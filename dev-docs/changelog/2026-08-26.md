## 2. `idea-aws` AWS 서버 구성 (신규)

trader 레포의 `trader-aws` 운영 패턴을 그대로 참고해 새 서버를 세팅했다.

| 항목 | 값 |
|---|---|
| 호스트 | `idea-aws` (Windows hosts 파일에 이미 등록: 43.203.241.72) |
| 인스턴스 | t4g.small (ARM, aarch64), 2GB RAM, 20GB |
| OS | Amazon Linux 2023 |

### 2-1. 기본 도구 설치

- `git` — dnf로 설치.
- `claude` CLI — **네이티브 바이너리**로 설치 (`curl -fsSL https://claude.ai/install.sh | bash`). Node.js/npm 불필요 (예전 npm 설치 방식과 다름, 사용자가 직접 정정).

### 2-2. GitHub 저장소 권한

- 서버 전용 ed25519 SSH 키(`~/.ssh/id_ed25519`, 코멘트 `idea-aws-deploy-key`) 생성.
- GitHub `hammaaa/idea` 저장소에 **Deploy key(쓰기 권한)**로 등록(사용자가 GitHub에서 직접 처리) → 서버가 이 레포 하나에만 clone/pull/push 가능.
- `~/idea`에 레포 클론, `~/.ssh/config`에 `github.com` 기본 identity 등록(매번 `GIT_SSH_COMMAND` 안 붙여도 됨), `git config user.name/email` = `hammaaa` / `hammaaa@gmail.com` 설정.

### 2-3. Remote Control 세션 (`rc_session.sh`)

- trader 레포의 `scripts/aws-claude/rc_session.sh`를 이 레포용으로 이식(`RC_NAME=idea-aws`, `RC_WORKDIR=~/idea`) → `scripts/aws-claude/rc_session.sh`.
- full-scope 로그인 필요 (`CLAUDE_CODE_OAUTH_TOKEN`은 추론 전용이라 Remote Control 목록에 안 뜬다 — trader 서버 구축 때 이미 겪은 문제). `rc_session.sh login`으로 헤드리스 OAuth 진행 → 사용자가 URL 승인 후 받은 코드를 전달 → 서버에 주입해 완료.
- 최초 `start` 후 목록에 안 떴던 이유: `claude --remote-control` 최초 실행 시 뜨는 **"이 폴더를 신뢰합니까?" 확인 프롬프트**에서 그냥 멈춰 있었음. `screen`에 Enter를 보내 확인 → 정상 등록.
- 검증: `ListAgents`에 `idea-aws · Remote Control · idle` 로 등재 확인.

### 2-4. 문서화

- `docs/aws/SERVER.md` 신설 — 접속 정보, 스펙, 설치 현황 체크리스트, Remote Control/git 권한 절차 정리.

## 4. 아이디어 등록 ① — 프롬프트 팩 (`docs/prompt-pack/`)

미리 만들어 둔 프롬프트 체인 + HTML 산출물 서비스. 출발점은 **삿포로 자유여행 일정을 ChatGPT로 짜는 데 2주가 걸린 실제 경험**(마지막 밤 노보리베츠, 송영버스·공항버스 예약, 비에이 데일리투어).

### 4-1. 핵심 통찰

2주가 걸린 원인이 모델 성능이 아니라 **프롬프트의 순서·제약·검증 단계를 사용자가 직접 발명해야 한다는 것**이었다. 그 발명은 한 번만 하면 재사용되므로 **상품이 된다.**

### 4-2. 재정의 — 여행 플래너가 아니다

구조를 벗겨보면 "고정 마감(귀국 항공편)에서 역산 → 실행 가능성 검증 → D-day 액션 리스트"이며, 이를 **제약 역산 엔진**으로 명명. 결혼 준비·창업 인허가·지원금 신청·이사에 그대로 이식된다.

### 4-3. 카테고리 재검토 (사용자 지적: "여행은 큰 의미 없는데")

7개 기준으로 점수화한 결과:

| 카테고리 | 합계 |
|---|:-:|
| 채용 키트 (JD→면접질문지·평가표) | **27** |
| 정부지원금·보조금 | 25 |
| 창업/개업 인허가 | 24 |
| 해외 자유여행 (원안) | **16** ← 최하위 |

- 여행이 꼴찌인 이유: **빈도 1점 + B2B 2점** (연 1~2회라 LTV가 1만 원대 → 유료 광고 불가)
- **세분화 원리: 팩은 좁을수록 강하다.** "유아 동반 홋카이도 렌트카"로 좁히면 이동 2시간 룰·카시트·수유실이 프롬프트에 하드코딩됨 → 그 축적이 상품. 다만 시장이 작아지므로 "좁은 팩 × 많은 개수" = **마켓플레이스가 세분화의 필연적 귀결**
- **숨은 제약 발견: 자체 검증 가능성.** 직접 겪지 않은 도메인은 결과의 정오를 판별할 수 없어 환각이 그대로 출고됨 → **법률·세무·의료는 이 모델로 건드리지 않는다**
- 권고: v0는 여행 유지(시장성이 아니라 **검증 속도** 때문), v1에서 채용 키트로 이동

### 4-4. 문서

`README.md` + `01-기획` `02-설계` `03-시장분석` `04-수익구조` `05-매출예측` `06-카테고리-확장`

## 5. 아이디어 등록 ② — 수식 맵 압축 (`docs/formula-map-compression/`)

**원안:** 비트를 생성하는 수식들에 번호를 매겨두고, 맵 번호 하나로 많은 바이트를 대체하는 압축.

대화가 진행되며 원안이 계속 정교해졌고, **매 단계를 실제 코드로 측정**해 문서 10개가 나왔다. 오늘 작업의 대부분이 여기에 들어갔다.

### 5-1. 검증 경과

| # | 사용자 제안 | 검증 방법 | 결과 |
|:-:|---|---|---|
| 01 | 고정 수식 맵, 범용 무손실 | 개수 세기 | ❌ 커버율 10^-607. 비둘기집으로 불가능 증명 |
| 02 | — | 대안 조사 | VQ·절차적 생성·신경망 압축·손실 생성 코덱 |
| 03 | "수식 1000개로 30%만 줄여도" | 실제 파일 블록 스캔 | ❌ 적중률 텍스트 0.0% / 바이너리 1.4~5.6% |
| 04 | "수식만 많으면" | 다항식 보간 실증 | ⚠️ 수식은 **항상 존재**하나 288바이트 > 원본 256바이트 |
| 05 | "수식 하나가 10바이트 커버" | 구간 측정 | ❌ 등차수열 6개 파일 전부 **0.0%** |
| 06 | **가변 길이, 맞는 데까지 확장, 짧으면 버림** | **압축기 직접 구현** | ⚠️ 설계는 옳음. 산술 수식만으론 로그가 **100.2%로 커짐** |
| 06 | +"앞에 나온 것 참조" 수식 하나 추가 | 같은 압축기 | ✅ **100.2% → 12.8%**. 참조가 나머지의 **756배** 커버 |
| 07 | "수식 10만 개" | `zstd --train` 실측 | ✅✅ 476B 레코드에서 **gzip 대비 69.3% 절감** |
| 08 | "사전 크면 해제 느려지지 않나" | 벤치마크 | ❌ 기우. 4KB→63KB에도 20→19ms. 오히려 **34% 빨라짐** |
| 09 | "바이트 패턴은 어떻게 구성되나" | 사전 바이너리 해부 | 목록이 아니라 **바이트 덩어리 하나**. LZ77 `[거리][길이]` 정확 매칭 |
| 10 | "압축 대상에서 뽑는 건가" | 정직한 회계 | ❌ 다른 샘플에서. 대상 자신으로 학습해도 **19.9%→18.6%뿐** |

### 5-2. 결론

> **원안의 직관 — "미리 공유된 맵의 번호 하나로 많은 바이트를 커버한다" — 은 처음부터 옳았다.**
> **틀린 것은 맵의 내용을 산술 수식으로 채우려 한 것뿐이다.**

- 실제 데이터는 수학적으로 규칙적이지 않다. **대신 자기 자신을 반복한다** → 가장 강력한 수식은 산술식이 아니라 "아까 그거"이고, 그 이름이 **LZ77**
- 사전이 공짜인 이유는 잘 만들어서가 아니라 **미리 가 있어서**다 → 사전은 압축 기술이 아니라 **배포 인프라**
- 실용 손익분기: **182건** 이상 압축할 때부터 사전이 이득 (사전 32KB ÷ 건당 절약 179.6B)

### 5-3. 작성한 측정 스크립트 (세션 스크래치패드)

`blockscan.py` `polyfit.py` `runscan.py` `varlen.py` `dicttest.py` `speedtest.py` `dictinspect.py` `honest.py`
