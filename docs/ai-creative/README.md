# 창작물 만들기 (Creative Works)

> **소설 · 웹툰 · 노래.** 셋 다 "만들고 싶다"인지 "만드는 도구를 팔고 싶다"인지가 먼저 갈려야 한다.

| 항목 | 내용 |
|---|---|
| 등록일 | 2026-09-01 |
| 상태 | 🌱 **아이디어 씨앗** (한 줄 원안, 조사 전) |
| 원안 | 소설 쓰기 · 웹툰 · 노래 만들기 |

---

## ⚠️ 먼저 갈려야 하는 것 — 작품인가, 도구인가

**이 셋은 각각 두 개의 완전히 다른 아이디어가 겹쳐 있다.**

| | **A. 작품을 만든다** | **B. 만드는 도구를 만든다** |
|---|---|---|
| 목표 | 소설 한 편, 웹툰 한 편, 노래 한 곡 | 창작 지원 서비스 |
| 성공 | 읽히는가 / 팔리는가 | 창작자가 돈을 내는가 |
| 필요한 것 | **작품성.** 취향과 시간 | 제품 개발 + 시장 |
| 이 레포의 다른 아이디어와 | 성격이 완전히 다름 | 3cushions·프롬프트 팩과 같은 계열 |
| 검증 | 만들어서 공개해 본다 | 지불 의사부터 확인 |

> **이 질문에 답하기 전에는 기획도 시장 조사도 의미가 없다.**
> "소설 쓰기"가 **취미**면 이 레포에 사업 문서로 쌓을 이유가 없고,
> **서비스**면 [프롬프트 팩](../prompt-pack/)과 같은 검증 절차를 밟아야 한다.

---

## 세 트랙 — 실제로 어려운 지점이 각각 다르다

| 트랙 | AI가 잘하는 부분 | **실제 병목** |
|---|---|---|
| **소설** | 문장 생성, 분량 채우기 | **긴 호흡의 일관성**과 **읽을 이유.** 분량은 이미 공짜고, 시장은 이미 AI 소설로 포화 중 |
| **웹툰** | 콘티, 대사, 배경 | **캐릭터 일관성**(같은 얼굴 유지)과 **연출.** 그림체 유지가 기술적 난제 |
| **노래** | 작곡·편곡·보컬 생성 | **곡이 아니라 「왜 들어야 하는가」.** 생성 자체는 이미 서비스가 여럿 |

> **셋의 공통점: 「만드는 것」은 이미 싸졌고, 「읽히는 것·들리는 것」이 병목이다.**
> 그래서 **작품 트랙(A)이든 도구 트랙(B)이든, 승부처는 생성이 아니라 유통과 발견**이다.

---

## 이 레포의 기준으로 평가하면

[프롬프트 팩 06번](../prompt-pack/06-카테고리-확장.md)에서 세운 **자체 검증 가능성** 기준을 적용한다.

| 기준 | 소설 | 웹툰 | 노래 |
|---|:-:|:-:|:-:|
| **자체 검증 가능성** | ⭐⭐ 읽어 보면 안다 | ⭐⭐ 보면 안다 | ⭐⭐ 들어 보면 안다 |
| 검증 비용 | 낮음 | **높음** (그림) | 낮음 |
| 피드백 속도 | 느림 (완결까지) | 느림 | **빠름** |
| 경쟁 | 매우 높음 | 높음 | 매우 높음 |
| 차별점이 될 만한 것 | ❓ 미정 | ❓ 미정 | ❓ 미정 |

> **당구(3cushions)와 달리 「정답이 객관적이지 않다.」**
> 당구는 쳐 보면 맞았는지 틀렸는지 즉시 갈리는데, 창작물은 **좋은지 나쁜지가 갈리지 않는다.**
> **이 레포가 지금까지 잘 다뤄 온 종류의 문제가 아니다** — 그걸 알고 시작해야 한다.

## 미해결 질문

| # | 질문 | 왜 결정적인가 |
|:-:|---|---|
| **1** | **작품인가 도구인가** (A/B) | **블로커.** 이게 정해지기 전엔 아무것도 못 씀 |
| **2** | **만들고 싶은 게 있는가** — 쓰고 싶은 이야기, 그리고 싶은 그림, 만들고 싶은 곡 | A라면 이게 전부다. 없으면 A는 성립하지 않는다 |
| 3 | 셋 다인가, 하나인가 | 셋을 동시에 하면 셋 다 안 된다 |
