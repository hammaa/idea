# 03. 시장 분석

> ⚠️ **이 문서의 수치는 대부분 추정이다.** 확정 통계 검증 전이며, 검증 필요 항목은 표기해두었다.

---

## 1. 시장 구조

### 상위 시장 — 한국인 해외 자유여행

| 항목 | 추정 | 검증 필요 |
|---|---|:-:|
| 연간 한국인 일본 방문객 | 수백만 명 규모 (코로나 이후 회복, 역대 최고 수준 갱신 보도 다수) | ✓ 공식 통계 확인 |
| 그중 자유여행(FIT) 비중 | 대다수 — 일본은 특히 개별여행 비율이 높음 | ✓ |
| 그중 "일정 설계에 어려움을 겪는" 층 | 미상 | ✓ 설문 필요 |

**시장 크기 자체는 문제가 아니다.** 문제는 아래 3개다.

### 진짜 봐야 할 것

| 질문 | 현재 판단 |
|---|---|
| 얼마나 자주 사는가? | ❌ **연 1~2회.** 최대 약점 |
| 얼마를 낼 의사가 있는가? | 🟡 ₩10,000 내외 추정. 검증 필요 |
| 대체재가 무료인가? | ❌ ChatGPT 무료 + 블로그 무료 |

→ **여행만으로는 사업이 작다.** 여행은 *검증용 비컨헤드*이지 최종 시장이 아닐 가능성이 높다.

## 2. 경쟁 지형

### A. LLM 직접 사용 (ChatGPT / Claude / Gemini)

- **가장 강력한 경쟁자이자 무료**
- 강점: 무료, 이미 다 쓰고 있음
- 약점: 프롬프트 설계 부담, 산출물 미보존, 검증 없음 ← **우리의 존재 이유**
- 위협: 모델이 좋아지고 에이전트화되면 이 격차가 줄어든다 → **시간 제한이 있는 기회**

### B. AI 여행 플래너 (Mindtrip, Layla, Wonderplan 등 해외 서비스 / 국내 유사 서비스)

- 강점: 자금·인지도
- 약점: 대체로 **관광지 추천 중심**. "송영버스 예약 시점", "온천 체크아웃 → 공항버스 → 수속 역산" 같은 **실행 디테일**은 약함
- 우리의 각: 추천이 아니라 **실행 가능성 검증 + 예약 액션**

### C. 프롬프트 마켓 (PromptBase 류)

- 강점: 선례 존재
- 약점: 프롬프트 텍스트만 팔고 실행/산출물이 없음, 품질 편차 큼
- 우리의 각: **실행까지 포함 + 결과물 보장**

### D. 여행 블로그 / 네이버 카페 / 유료 전자책

- 강점: 무료, SEO 강력, 신뢰도(실제 다녀온 사람)
- 약점: **남의 일정.** 내 항공편·인원·날짜에 안 맞음
- 우리의 각: 개인화

### E. 여행사·OTA (마이리얼트립, 클룩, KKday)

- 상품 판매가 본업. 일정 설계는 미끼
- **경쟁자가 아니라 제휴 대상** (→ [04-수익구조.md](04-수익구조.md) 어필리에이트)

## 3. 차별화 포지셔닝

```
                실행 디테일 강함
                       ▲
                       │
                   [우리]
                       │
   개인화 약함 ◄───────┼───────► 개인화 강함
                       │
   블로그/전자책        │      AI 여행 플래너
                       │      ChatGPT 직접
                       ▼
                실행 디테일 약함
```

한 문장: **"예쁜 추천이 아니라, 실제로 예약 가능한 일정."**

## 4. 진입 전략

### 왜 일본 / 홋카이도부터인가

1. 직접 겪은 문제 → 프롬프트 품질을 스스로 검증 가능
2. 홋카이도는 **광역 이동 + 온천 + 시즌 투어**가 겹쳐 난이도 최상 → 가치가 가장 크게 드러남
3. 한국인 방문 수요가 크고 검색량이 많음
4. 성공 시 간사이/규슈/오키나와로 템플릿 복제 용이

### 초기 유통 채널

| 채널 | 방법 | 비용 |
|---|---|---|
| 커뮤니티 | 네이버 여행 카페, 디시 여행갤, 클리앙 — **삿포로 일정 산출물 무료 공개** 후 반응 확인 | 0 |
| SEO/블로그 | "노보리베츠 송영버스 예약", "온천에서 신치토세 공항버스" 같은 롱테일 키워드 | 시간 |
| 스레드/인스타 | 산출물 스크린샷이 시각적으로 강함 | 0 |
| 공유 링크 | 동행자에게 일정 공유 = 자연 확산 | 0 (제품 내장) |

**v0에서 광고비는 쓰지 않는다.** 커뮤니티 반응이 안 나오면 그게 답이다.

## 5. 리스크

| # | 리스크 | 심각도 | 대응 |
|:-:|---|:-:|---|
| 1 | **환각으로 잘못된 정보 제공** → 여행 망침, 신뢰 즉사 | 🔴 최상 | 신뢰도 등급 + 확인필요 목록 전면 배치 ([02-설계.md](02-설계.md) 5절) |
| 2 | **재구매 주기가 김** (연 1~2회) | 🔴 최상 | 여행 외 버티컬 확장, B2B/화이트라벨 |
| 3 | **LLM이 좋아져 격차 소멸** | 🟠 상 | 실데이터·오답 DB로 해자 이동. 시간 제한 있는 기회로 인식 |
| 4 | **무료 대체재** (ChatGPT, 블로그) | 🟠 상 | "산출물 + 실행 검증"으로 차별. 가격을 낮게 |
| 5 | 프롬프트 복제 | 🟡 중 | 체인·템플릿·데이터로 방어 |
| 6 | API 원가 > 판매가 | 🟡 중 | 단계별 모델 분리, 캐싱, 크레딧제 |
| 7 | 대형 플레이어 진입 | 🟡 중 | 니치 깊이로 방어, 빠른 검증 |
