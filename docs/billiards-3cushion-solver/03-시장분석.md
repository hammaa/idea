# 03. 시장 분석 — 이미 만들어졌고, 아무도 못 팔았다

조사일 2026-08-30

---

## 1. 경쟁 서비스 정밀 분석

### 3ball.app — 무료라는 가장 나쁜 경쟁자

| 항목 | 내용 |
|---|---|
| 형태 | 웹 브라우저 + PWA (WebGL2), 계정 불필요 |
| 솔버 | **머신러닝 미사용, 순수 물리 기반 탐색.** 직접·쿠션우선·매시/피케 후보를 평가하고 순위 매김 |
| 물리 | 2D 물리 모델 (공·쿠션·스핀·천 반응), "Physics V3" |
| 입력 | **사진 정렬** — 로컬 비전으로 코너·공 위치 자동 제안 + 수동 편집 |
| 시스템 교육 | **Corner-5, Plus-2, Korean 시스템** 학습 페이지 |
| 언어 | 9개 |
| **가격** | **완전 무료. 계정 없음, 페이월 없음.** 선택적 광고 |
| 저장 | 로컬 스토리지 |

> **원안의 기능 1·2·5·6이 여기 전부 있고, 공짜다.**
> "무료 대안이 존재한다"는 것은 **가격 상한이 0에 붙어 있다**는 뜻이다.

### Bricole — 유료 완성품인데 사용자가 없다

| 항목 | 내용 |
|---|---|
| 형태 | iOS 앱, 오프라인 동작 |
| 기능 | **8개 시스템** 각각의 공식과 **적용 범위**, 궤적 다이어그램(쿠션에 순서대로 번호), **키스 경고**, **테이블 캘리브레이션**, 드릴 64개, 일일 퍼즐, 스트릭 |
| 시스템 | Corner-5, Plus, **Reverse, Cross-Table, End-Rail** |
| 언어 | 영어, 터키어, **한국어**, 베트남어 |
| **가격** | 무료 + **$4.99/월 / $39.99/년 / $89.99 평생** |
| 출시 | 2024-07-02, 최근 업데이트 1.3.3 (2024-08-21) |
| **평점** | **"평점·리뷰가 충분히 쌓이지 않음"** |

> **이게 이 아이디어에서 가장 중요한 한 줄이다.**
> **완성도 높은 유료 앱이, 한국어를 지원하면서, 1년 넘게 평점이 쌓일 만큼의 사용자도 못 모았다.**

### 오픈소스 물리 엔진

| 프로젝트 | 함의 |
|---|---|
| [tailuge/billiards](https://github.com/tailuge/billiards) | 백스핀·사이드스핀·쿠션 반발이 잘 모델링된 3쿠션 트레이너. WebGL |
| [pooltool](https://ekiefl.github.io/2021/03/25/pooltool-start/) | 방정식→코드 전환이 문서화된 파이썬 시뮬레이터 |

> **기술 해자가 없다.** 물리 엔진은 공개되어 있고, 남은 건 데이터와 UX다.

## 2. 한국 당구 시장 — 숫자는 크지만 깔때기가 좁다

### 겉보기 규모

| 지표 | 수치 | 출처 |
|---|---:|---|
| 전국 당구장 | **2만~2만5천 개** (세계 최다) | 문체부 2018 |
| 당구장 + 용품 시장 | **2조 2천억 원** | 업계 집계 |
| 하루 당구 인구 | 약 **270만 명** | 업계 집계 |
| 당구 동호인 | **1,000만 명** | 업계 집계 |
| PBA 프로선수 (2019 출범 시) | 남 128 / 여 64 = **192명** | — |

⚠️ **270만·1,000만은 업계·언론 인용치이고 산출 근거가 불명확하다.** 그대로 믿고 매출을 계산하면 안 된다.

### 깔때기 — 여기서 다 죽는다

```
당구 동호인                       1,000만 명 (주장치)
   │  ├─ 대부분 4구를 친다
   ▼
3쿠션을 치는 인구                    ??? (자료 없음)
   │  ├─ PBA·국제식 대대 보급으로 증가 추세이나 여전히 소수
   ▼
시스템을 "공부"하는 인구              ???
   │  ├─ 대부분은 감으로 친다. 숫자를 외우는 건 상급 취미층
   ▼
앱에 돈을 낼 인구                     ???
   │  ├─ 유튜브에 무료 강의가 대량으로 존재
   │  ├─ 3ball이 완전 무료
   ▼
결제 전환                            Bricole 실적이 이미 답을 암시
```

> **"당구장 2만 5천 개"는 이 제품의 시장이 아니다.**
> 이 제품의 시장은 **"3쿠션을 치면서 다이아몬드 시스템을 숫자로 공부할 의향이 있고, 무료 대안 대신 돈을 낼 사람"** 이고,
> 그 수는 **아무도 모르며, 조사 결과 매우 작을 가능성이 높다.**

## 3. 왜 안 팔렸을까 — 가설 5개

Bricole이 실패에 가까운 이유를 추정한다. **이 중 어느 것이 맞느냐가 재도전 가능 여부를 결정한다.**

| # | 가설 | 재도전 가능? |
|:-:|---|:-:|
| **1** | **테이블에서 쓸 수 없다.** 경기 중에 폰을 보며 계산할 수 없고, 매너·룰 문제도 있다 → 집에서 보는 학습 도구가 되는데, 학습 도구는 지불 의향이 낮다 | ⚠️ 제품 형태를 바꿔야 함 (→ **감도표는 외워지는 형태**라 이 문제를 우회) |
| **2** | **무료 대안(3ball)이 가격을 0으로 눌렀다** | ❌ 구조적 |
| **3** | **유튜브가 이미 무료로 가르친다.** 한국어 3쿠션 시스템 강의가 대량으로 존재 | ❌ 구조적 |
| **4** | **마케팅 부재.** 좋은 제품이지만 3쿠션 커뮤니티에 도달하지 못함 | ✅ **재도전 가능** |
| **5** | **시장 자체가 작다** | ❌ 구조적 |

> **4번이면 해볼 만하고, 2·3·5번이면 하면 안 된다.**
> **그리고 이건 앉아서 판단할 수 없다** — 3쿠션 커뮤니티에 물어봐야 답이 나온다.

## 4. 진입한다면 남은 자리

| 자리 | 근거 | 난이도 |
|---|---|---|
| **팁 감도 / 괴리 진단** | 경쟁 서비스에서 확인되지 않음. 원안 3번 | 중 |
| **테이블별 보정 데이터베이스** | 캘리브레이션 결과를 장소 단위로 축적 → **복제 불가 자산** | 높음 (사용자 필요) |
| **한국 시장 특화** | Bricole은 한국어를 지원하지만 한국 시스템 관행(중대/대대, 국내 용어)에 최적화되지 않았을 가능성 | 낮음 |
| **B2B — 당구장 / 코치** | 2만 5천 개 당구장, PBA 생태계. 다만 당구장의 지불 여력·의향은 미확인 | 높음 |

## 5. 종합

| 축 | 평가 |
|---|:-:|
| 기술 실현 가능성 | ⭐⭐⭐ (오픈소스 엔진 존재) |
| 자체 검증 가능성 | ⭐⭐⭐ (당구대에서 즉시 확인) |
| 차별화 여지 | ⭐ (원안 7개 중 1개만 미점유) |
| **시장 크기** | ⭐ (깔때기가 심하게 좁음) |
| **경쟁** | ❌ (완성품 2개, 그중 하나 무료) |
| 지불 의향 | ❓ **미검증 — Bricole 실적이 부정적 신호** |

> **한 문장:** **만들 수 있는가는 이미 답이 나왔고(예), 팔리는가는 이미 반증에 가까운 증거가 있다.**
> **그래서 다음 단계는 개발이 아니라, 3쿠션 커뮤니티에 "이거 돈 내고 쓰겠나"를 직접 묻는 것이다.**
