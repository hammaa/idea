## 세 개가 하나의 축 위에 있다

| | 땅먹기 | 지반붕괴 | 명당 만들기 |
|---|---|---|---|
| 자원 | **공간** | **공간** | **공간** |
| 방향 | 늘린다 | **줄어든다** | 고른다 |
| 승리 | 많이 먹기 | 오래 버티기 | 잘 고르기 |
| 심리 | 남의 확장을 막기 | **남을 무너지게 유도** | 남이 안 갈 곳 예측 |
| 긴장의 출처 | 경쟁 | **소멸** | 정보 비대칭 |

> **셋 다 "공간을 두고 벌이는 심리전"이고 방향만 다르다.**
> **하나의 보드 엔진(영역 계산) 위에 규칙만 바꿔 얹을 수 있다.**
> 이건 [던지기 물리 게임](../throwing-physics-games/)이 하나의 물리 엔진을 공유하는 것과 같은 구조다.

### 세 개 중 가장 특이한 것은 지반붕괴

땅먹기와 명당 만들기는 흔한 발상이지만, **밟은 자리가 무너진다**는 규칙은 성격이 다르다.

| | 보통의 영역 게임 | **지반붕괴** |
|---|---|---|
| 내 행동의 결과 | 내 영역이 **늘어난다** | 내 발판이 **사라진다** |
| 잘하면 | 유리해진다 | **선택지가 줄어든다** |
| 긴장 | 남과의 경쟁 | **자기 자신과의 경쟁** |

> **"움직일수록 갈 곳이 없어진다"는 구조는 그 자체로 게임이 된다.**
> 세 개 중 **먼저 프로토타입할 값어치가 가장 크다.**

## 이 장르의 핵심 조건

「지니어스」·「데블스 플랜」이 재미있는 이유는 게임이 복잡해서가 아니다.

| 조건 | 내용 |
|---|---|
| **규칙은 5분** | 설명이 길면 그 자리에서 죽는다 |
| **전략은 안 끝난다** | 규칙이 단순한데 최적해가 안 보여야 한다 |
| **선택이 공개된다** | 남의 수가 보여야 심리전이 생긴다 |
| **한 판이 짧다** | 져도 바로 다시 |
| **배신·협력이 가능** | 2인 대전보다 **3~6인**에서 살아난다 |

> ⚠️ **가장 어려운 건 게임 디자인이 아니라 「규칙은 단순한데 전략이 깊은」 균형점 찾기다.**
> 그건 문서로 못 만들고 **종이로 만들어 사람과 쳐 봐야 나온다.**

## 미해결 질문

| # | 질문 | 왜 중요한가 |
|:-:|---|---|
| **1** | **몇 인 대전인가** | 2인이면 순수 전략, 3인 이상이면 **배신·연합**이 들어온다. 장르가 완전히 달라진다 |
| **2** | **동시 진행인가 턴제인가** | 짧게 끝나려면 동시 진행이 유리하고, 심리전은 턴제가 깊다 |
| 3 | 실시간 매칭인가 비동기인가 | 짧은 판은 매칭 대기가 더 길어질 수 있다 |
| 4 | 모여서 하는가(같은 방) 온라인인가 | 배신 게임은 얼굴이 보일 때 훨씬 재미있다 |
| 5 | 세 개를 다 만드나, 하나만 만드나 | 엔진은 공유되지만 **재미는 개별로 검증해야 한다** |

> **1번이 블로커다.** 인원수가 정해져야 나머지 설계가 시작된다.
