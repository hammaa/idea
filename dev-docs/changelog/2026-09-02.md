## 2. "망치에 공 올리는 게임" = 켄다마 (けん玉)

사용자가 이름을 몰라 물었고, 확인했다.

> **한 손에 쥘 수 있는 막대기에 오자라(큰 접시)·코자라(작은 접시)가 붙어
> 마치 망치와 같은 모양새.** 공을 제외한 전체를 **켄**, 공을 **다마**라 한다.

*(한국에서 죽방울로도 불리나, 엄밀히 죽방울은 디아볼로에 대응한다는 지적이 있다.)*

### ⭐ 켄다마가 묶음의 범위를 넓힌다

| | 나머지 다섯 | **켄다마** |
|---|---|---|
| 물체 | 자유낙하 | **끈에 매달린 구속 진자** |
| 조작 | 던지는 순간 | **받는 순간** (+ 손목으로 계를 계속 흔든다) |
| 실패 원인 | 조준·세기 | **공이 돌아서** — 다마가 회전하면 접시에 못 얹힌다 |
| 기술의 핵심 | 궤적 설계 | **소프트 캐치** — 받는 순간 상대속도를 0으로 |

> **"공의 회전을 죽이는 것"이 기술의 절반이고, 이건 3쿠션에서 다룬 스핀 감쇠와 같은 축이다.**
> **"받는 순간 상대속도 0"은 공-벽 게임의 받기와 같은 문제 — 엔진이 이미 갖고 있어야 할 것들이라 추가 비용이 작다.**

⚠️ 다만 켄다마는 다른 소재와 달리 **실물이 이미 유행했다** —
수요가 확인돼 있다는 강점이자, **실물이 더 재미있으면 진다**는 위험. 미해결 질문에 추가.

### 묶음 이름 조정

켄다마는 던지기가 아니라 받기라서, 묶음을 **「던지기·받기 물리 게임」** 으로 넓혔다.
디렉토리명 `throwing-physics-games`는 링크가 깨지지 않게 그대로 뒀다.
