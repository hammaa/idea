# 핀토이 (Pin Toy) — 별판 경주 게임

> **육각별 판 위에서 한 칸씩 가거나 말을 뛰어넘어 반대편 진영에 먼저 도착하는 게임.**
> 차이니즈 체커 / 다이아몬드 게임 계열. **규칙은 두 줄, 전략은 안 끝난다.**

| 항목 | 내용 |
|---|---|
| 등록일 | 2026-09-01 |
| 상태 | 🌱 **아이디어 씨앗** — [짧은 네트워크 대전 게임](../quick-match-party-games/)에서 분리 |
| 분리 사유 | **엔진도 장르도 다르다** — 저쪽은 영역 계산, 이쪽은 그래프 경로 탐색 |

## 규칙 (공개 도메인)

| 항목 | 차이니즈 체커 | 다이아몬드 게임 |
|---|---|---|
| 판 | 다윗의 별(육각별) | 같은 모양, **더 작다** |
| 인원 | **2~6인** | 2~3인 |
| 말 | 각 진영 | **10개** |
| 시작 배치 (2인) | **180° 반대편** | 중심 기준 **120°** |
| 이동 | 인접 한 칸 | 같음 |
| 점프 | 말 하나 뛰어넘기, **연속 가능** | 같음 |
| 승리 | 내 말 전부를 **맞은편 진영**에 | 같음 |

**규칙이 공개 도메인이라 자유롭게 구현할 수 있다.**

---

## ⭐ 이 게임의 진짜 축 — 적대적 협력

> **상대의 말이 내 징검다리가 된다.**
> 연속 점프는 남의 말을 밟고 가는 것이라, **상대를 막으면 내 길도 막힌다.**
> 길을 열어 주면서 내가 더 이득을 보는 배치를 찾는 것 — 그게 이 게임이다.

**"규칙은 단순한데 전략이 깊다"의 교과서적 사례**이고,
[짧은 대전 게임 묶음](../quick-match-party-games/)이 노리던 성질을 이미 갖고 있다.

| 조건 | 핀토이 |
|---|:-:|
| 규칙은 5분에 배운다 | ✅ **두 줄이면 끝** |
| 전략은 안 끝난다 | ✅ 점프 사슬 설계가 사실상 무한 |
| 선택이 공개된다 | ✅ 판이 전부 보인다 |
| 3~6인 배신·연합 | ✅ **2~6인** |
| **한 판이 짧다** | ❌ **말 10개를 다 옮겨야 끝난다** |

---

## 핵심 설계 질문 — 어떻게 짧게 만드나

원안의 요구가 **"짧게 끝나기"** 인데 정석 룰은 길다. 줄일 수 있는 축이 넷 있고, **각각 게임의 성격을 다르게 바꾼다.**

| 축 | 줄이는 법 | 성격 변화 |
|---|---|---|
| **말 개수** | 10개 → 4~6개 | 사슬이 짧아진다. **징검다리가 줄어 적대적 협력이 약해진다** ⚠️ |
| **판 크기** | 다이아몬드 게임처럼 축소 | 밀도가 올라가 **사슬은 오히려 길어진다** ✅ |
| **승리 조건** | 전부 → **과반만** 도착 | 마무리의 지루한 구간이 사라진다 ✅ |
| **턴 제한** | 샷클럭 | 심리전이 얕아진다 ⚠️ |

> **판을 줄이고 승리 조건을 과반으로 낮추는 조합이 유력하다.**
> 말을 줄이면 이 게임의 핵심(긴 점프 사슬)이 같이 죽는다.
>
> **⚠️ 이건 종이로 몇 판 해 보면 한 시간에 답이 나온다.** 문서로 더 따질 일이 아니다.

## 경쟁 현실

**차이니즈 체커는 이미 온라인·모바일 구현이 매우 많다.** 공개 도메인이라 진입장벽이 없다.
**"만들 수 있는가"는 질문이 아니고, "왜 이걸 쓰겠는가"가 질문이다.**

### 차별점 후보 — 이 레포의 다른 아이디어와 같은 철학

| 후보 | 내용 | 왜 다른가 |
|---|---|---|
| **짧은 변형** | 3~5분에 끝나는 공식 룰셋 | 기존 구현은 대개 정석 룰. **원안의 요구가 곧 차별점** |
| ⭐ **점프 사슬 시각화** | 가능한 점프 경로를 보여주되 **최선은 안 알려준다** | 이 게임의 재미는 긴 사슬을 **발견하는 것**인데, 대부분 구현이 그걸 안 도와준다 |
| ⭐ **적대적 협력 지표** | "이 수는 상대에게 몇 칸을 열어준다" | **이 게임의 심리 축을 수치로 드러낸다.** 아무도 안 하고 있다 |

> ### 이건 [3cushions](../billiards-3cushion-solver/)와 같은 철학이다
> **계산은 보여주되 답은 주지 않는다.**
> 당구에서 "시스템 계산과 실제의 괴리"를 보여주듯,
> 여기서는 **"내 수가 상대에게 무엇을 열어주는가"** 를 보여준다.
> 둘 다 **정답을 대신 내주는 게 아니라 판단 재료를 주는 도구**다.

## 미해결 질문

| # | 질문 | 왜 중요한가 |
|:-:|---|---|
| **1** | **몇 분에 끝나야 하나** | 3분? 5분? 이 숫자가 정해져야 변형 설계가 시작된다 |
| **2** | **몇 인 기준으로 설계하나** | 2인은 순수 전략, **4~6인은 연합·배신**. 완전히 다른 게임 |
| 3 | 실시간인가 비동기(턴 알림)인가 | 짧은 판은 매칭 대기가 더 길 수 있다 |
| 4 | 적대적 협력 지표가 **재미를 더하나 깎나** | 다 보여주면 심리전이 죽을 수도 있다 |
