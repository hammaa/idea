# 01. 정보공개청구 제도 — 청구해서 받는 법

> 근거: **「공공기관의 정보공개에 관한 법률」**(정보공개법). 창구: **[정보공개포털 open.go.kr](https://www.open.go.kr/)**
> 조사일 2026-08-30

---

## 1. 무엇을 청구할 수 있나 — 범위가 생각보다 넓다

**대상은 "데이터"가 아니라 "기관이 이미 보유·관리하는 문서"다.**

| 청구 가능 | 청구 불가 |
|---|---|
| 결재문서, 회의록, 보고서, 계획서 | 기관이 **갖고 있지 않은** 정보 |
| 예산 집행 내역, 계약서, 정산서 | **새로 만들어야** 나오는 정보 (가공·분석·통계 신규 산출) |
| 감사 결과, 점검 결과, 처분 내역 | 단순 질의·의견 요청 (→ 민원으로 처리됨) |
| 인허가 서류, 신고 접수 자료 | 다른 법률이 비공개로 정한 정보 |
| 전자 파일, DB에서 추출 가능한 목록 | |

> **가장 흔한 실수:** "○○ 현황을 분석해 주세요"는 청구가 아니다.
> **"○○에 대해 2025년에 작성된 보고서 일체"** 처럼 **문서를 특정**해야 한다.
> 다만 기관이 이미 전자적으로 보유한 자료를 **단순 추출·출력**하는 정도는 "새로 만드는 것"이 아니라고 본다.

### 청구 전에 먼저 볼 것 — 사전정보공표 / 원문공개

- **사전정보공표**: 기관이 청구 없이도 미리 공표하도록 정한 정보 목록. 각 기관 홈페이지 정보공개 메뉴에 있다.
- **원문공개**: 결재 완료된 문서 원문을 정보공개포털에서 바로 열람. **청구 없이 검색으로 나온다.**

**청구서를 쓰기 전에 이 둘부터 검색하면 10일을 아낀다.**

---

## 2. 누가, 어디에 청구하나

### 청구권자

| 대상 | 자격 |
|---|---|
| **모든 국민** | 자연인·법인·단체 모두. **이유를 밝힐 필요가 없다** |
| 외국인 | 일정 요건 하에 가능 (여권 또는 외국인등록번호 제출) |

> **"왜 필요하냐"는 요구는 법적 근거가 없다.** 목적을 묻더라도 답할 의무가 없고, 목적을 이유로 거부할 수도 없다.
> (단, **수수료 감면**을 받으려면 공익 목적임을 소명해야 한다.)

### 대상 기관

국가기관(입법·행정·사법), 지방자치단체, 공공기관, **각급 학교**, 지방공사·공단 등 — 매우 넓다.
정보공개포털 통계 기준 **3만 개 이상**의 기관이 등록되어 있다.

### 청구 방법

| 방법 | 경로 |
|---|---|
| 온라인 | **[정보공개포털](https://www.open.go.kr/)** (통합 창구), [정부24](https://www.gov.kr/) |
| 오프라인 | 방문·우편·팩스 |

---

## 3. 처리 절차와 기한 — 날짜를 알면 절반은 이긴다

```
청구 접수
  │
  ├─ 10일 이내 : 공개 여부 결정                      ← 법정 기한
  │     └─ 부득이한 사유 시 10일 연장 가능 (통지 필수)  → 최대 20일
  │
  ├─ 제3자 관련 정보면 : 제3자에게 통지 → 제3자는 3일 이내 비공개 요청 가능
  │
  └─ 공개 결정 시 : 결정일부터 10일 이내 실제 공개
```

| 상황 | 기한 |
|---|---:|
| 공개 여부 결정 | 청구일부터 **10일** |
| 연장 (사유 통지 필수) | **+10일** |
| 결정 후 실제 공개 | **10일 이내** |
| **20일이 지나도 결정이 없으면** | **이의신청 가능** (비공개로 간주하고 다투기 시작) |

### 수수료

- **청구인 부담**이 원칙 (복사비·우송료 실비 수준)
- **전자파일 교부는 대개 무료이거나 매우 저렴** → 가능하면 **전자파일**로 청구할 것
- 공익 목적 등은 감면 가능

---

## 4. 비공개 사유 — 법 제9조 제1항의 8개 호

**여기 없으면 공개해야 한다.** 거부 통지를 받으면 **몇 호인지 반드시 확인**하고, 그 호의 요건에 실제로 해당하는지 따져야 한다.

| 호 | 사유 | 실무에서 자주 쓰이는 지점 |
|:-:|---|---|
| **1** | 다른 법률·법규명령이 비밀·비공개로 규정한 정보 | 가장 강력. **어느 법 몇 조인지 반드시 물어야 한다** |
| **2** | 국가안전보장·국방·통일·외교 관련, 국익을 해칠 우려 | |
| **3** | 국민의 생명·신체·재산 보호에 현저한 지장 | |
| **4** | **진행 중인 재판** 관련, 범죄 수사·공소·형 집행·교정·보안처분 | "진행 중"이 끝나면 사정 변경 → **재청구 여지** |
| **5** | 감사·감독·검사·시험·규제·입찰계약·기술개발·인사관리·**의사결정 과정 또는 내부검토 과정** | **가장 남용되는 호.** 의사결정이 끝났으면 공개 대상이 된다 |
| **6** | **개인정보**로 사생활의 비밀·자유를 침해할 우려 | 비공개 사유 1위 |
| **7** | 법인·단체·개인의 **경영상·영업상 비밀** | 계약·보조금 건에서 자주 등장 |
| **8** | 부동산 투기·매점매석 등 특정인에게 이익·불이익을 줄 우려 | |

### 실제 비공개 사유 분포

| 사유 | 비중 |
|---|---:|
| 개인정보 보호 (6호) | **34%** |
| 재판 관련 (4호) | 17% |
| 공정한 업무수행 지장 (5호) | 15% |
| 법인 영업상 비밀 (7호) | 14% |
| 법령상 비밀 (1호) | 13% |

> **6호 + 7호 = 48%.** 비공개의 절반이 "제3자의 정보라서"다.
> 이 벽은 논리로 못 넘는다 — **비식별 처리한 형태로 다시 청구**하거나, 애초에 개인 단위가 아닌 **집계 문서를 특정**해서 청구해야 한다.

### 부분공개가 원칙이다

**비공개 부분을 가리고 나머지는 공개**하는 것이 법의 요구다.
"개인정보가 포함되어 있어 전부 비공개"는 그 자체로 다툴 여지가 있다 — **가릴 수 있으면 가리고 주어야 한다.**

## 5. 불복 — 3단계, 기한이 다르다

| 단계 | 기한 | 상대 | 특징 |
|---|---|---|---|
| **① 이의신청** | 결정 통지받은 날 또는 **청구 후 20일 경과일**부터 **30일 이내** | 그 공공기관 | 문서로. 생략 가능 |
| **② 행정심판** | 처분을 안 날부터 **90일 이내** | 행정심판위원회 | **이의신청을 거치지 않아도 바로 가능** |
| **③ 행정소송** | 처분을 안 날부터 **90일**, 있은 날부터 **1년** | 법원 | |

**제3자(자기 정보가 공개되는 쪽)의 기한은 훨씬 짧다:**

| 제3자 행위 | 기한 |
|---|---|
| 비공개 요청 | 공개 청구 사실을 통지받은 날부터 **3일 이내** |
| 공개 결정에 대한 이의신청 | 공개 통지를 받은 날부터 **7일 이내** |

> **주의:** 청구인의 이의신청은 30일, 제3자의 이의신청은 7일이다. 자주 혼동된다.

---

## 6. 실무 요령

| 상황 | 요령 |
|---|---|
| 어느 기관이 갖고 있는지 모름 | 정보공개포털 **원문공개 검색**으로 유사 문서를 먼저 찾아 생산 기관을 역추적 |
| 문서명을 모름 | "○○에 관하여 2025년 중 생산된 문서 일체" + 기간·주제로 한정 |
| 양이 많다며 거부 | 기간을 쪼개 **여러 건으로 분할 청구** |
| 새로 만들어야 한다며 거부 | "**보유 중인 원본 그대로**" 달라고 재청구 (가공을 요구하지 않음을 명시) |
| 1호(다른 법률)로 거부 | **근거 법률의 조문 번호**를 명시하라고 요구 |
| 5호(의사결정 과정)로 거부 | **의사결정이 종료되었는지** 확인 → 종료됐으면 재청구 |
| 20일이 지나도 무응답 | 비공개 간주 → **이의신청 개시** |
| 파일이 필요함 | 청구서에 **교부 방법을 "전자파일"로 명시** (수수료·시간 절약) |

## 7. 이 제도의 구조적 한계

| 한계 | 내용 |
|---|---|
| **1건 = 1문서** | 대량·반복 수집에 부적합. 그건 ② 공공데이터 개방의 영역 |
| **형식이 통제되지 않음** | HWP/PDF 스캔본으로 오는 경우가 흔하다. 기계판독을 보장하지 않는다 |
| **기관별 편차** | 같은 성격의 청구도 기관에 따라 공개/비공개가 갈린다 |
| **부분공개의 재량** | 어디까지 가릴지가 기관 판단이라 결과 품질이 균일하지 않다 |
| **단일 장애점** | 2025-09-26 국가정보자원관리원 화재로 정보공개포털이 중단, **10-31에야 청구·이의신청 서비스 재개** |
