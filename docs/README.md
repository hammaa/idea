## 각 아이디어의 다음 한 걸음

**전부 "문서를 더 쓰는 것"이 아니라 "밖에 나가서 확인하는 것"이다.**

| 아이디어 | 다음 한 걸음 | 규모 |
|---|---|---|
| 3쿠션 당구 | **P1 물리 솔버 프로토타입** (씬·UI 없이 공 3개) → 실제 당구대와 대조 | 2~4주 |
| 〃 | **P2 조준 시퀀스 프로토타입** — 재미있는지 지루한지 | 2~4주 |
| 〃 | [감도 계산기](billiards-3cushion-solver/mockup/)로 **지불 의사 확인** | 화면은 준비됨 |
| 〃 | 파이브앤하프 눈금표 **당구대 검증** (수구수 50 → 1쿠션 30 → 3쿠션 20) | 한 시간 |
| 던지기 게임 | **벽 역산 실험** — 세 번 던져서 반발계수·마찰이 얼마나 정확히 나오나 | 반나절 |
| 공간 심리전 | **지반붕괴 종이 프로토타입** | 하루 |
| 핀토이 | **단축 변형 실험** — 판 축소 + 승리 조건 과반, 실제 소요 시간 측정 | 한 시간 |
| 창작물 | **A/B 결정** (작품 vs 도구) | 한 문장 |
| 수식 맵 압축 | `zstd --train` **자기 데이터 실측** — 작은 파일 많이 나오는 워크로드 필요 | 반나절 |
| 프롬프트 팩 | **삿포로 산출물 1건** 만들어 공개 → 유료 10건 나오나 | — |
