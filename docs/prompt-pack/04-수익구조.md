# 04. 수익 구조 및 수익 방법

## 1. 과금 모델 비교

| 모델 | 가격안 | 장점 | 단점 | 평가 |
|---|---|---|---|:-:|
| **A. 단건 판매** | 생성 1회 ₩9,900 | 이해 쉬움, 여행 주기와 맞음 | 매출 예측 불가, LTV 낮음 | ⭐ 시작용 |
| **B. 구독** | 월 ₩9,900 / 연 ₩79,000 | MRR, 예측 가능 | **연 1~2회 쓰는데 왜 구독?** 해지율 폭발 | ❌ 여행 단독으론 부적합 |
| **C. 크레딧** | 10크레딧 ₩15,000 (생성 1회 = 3크레딧) | 재실행·수정에 자연스럽게 과금 | 이해 부담 | ⭐ v1 유력 |
| **D. 프리미엄 무료** | 기본 무료 + HTML 산출물/검증 유료 | 유입 극대화 | 원가가 무료 유저에서 발생 | ⭐ 병행 |
| **E. 어필리에이트** | 예약 링크 커미션 | 사용자 추가 부담 0 | 전환 추적 어려움, 단가 낮음 | ⭐ 부가 |
| **F. B2B 화이트라벨** | 월 ₩200,000~ | 객단가 높음, 재구매 문제 해결 | 영업 필요 | ⭐⭐ 확장 핵심 |

### 권장 조합

```
v0  →  A 단건 (₩9,900)                   … 지불 의사 검증만
v1  →  D 프리미엄 무료 + C 크레딧 + E 어필리에이트
v2  →  + F B2B 화이트라벨               … 여기서 사업 규모가 결정됨
```

**핵심 판단:** 여행 버티컬의 재구매 주기 문제([03-시장분석.md](03-시장분석.md) 리스크 2)는 과금 모델로 못 푼다. **B2B 또는 버티컬 확장으로만 풀린다.**

## 2. 프리미엄 무료 경계선

무료로 줄 것과 돈 받을 것의 경계가 곧 상품 정의다.

| 무료 | 유료 |
|---|---|
| 숙박 도시 골격 (②단계) | **구간 교통 연결 검증 (③단계)** ← 진짜 가치 |
| 간단한 일정 미리보기 | **예약 액션 리스트 (④단계)** ← 진짜 가치 |
| 워터마크 있는 화면 보기 | HTML 산출물 다운로드 / 공유 링크 / 오프라인 사본 |
| 1회 생성 | 재실행·부분 수정 |

무료 구간에서 "아, 이거 진짜 잘 짜네"를 느끼게 하고, **실행 정보에서 결제**시킨다.

## 3. 원가 구조

### 생성 1회당 LLM 원가 (추정)

체인 5단계, 단계별 모델 분리 가정:

| 단계 | 모델 등급 | 예상 토큰 | 비고 |
|---|---|---|---|
| ① 제약 정규화 | 소형 | 소 | 단순 구조화 |
| ② 골격 설계 | 중형 | 중 | |
| ③ **교통 검증** | **대형** | **대** | 원가의 대부분. 품질 타협 불가 |
| ④ 액션 리스트 | 중형 | 중 | |
| ⑤ 렌더 | 소형/코드 | 소 | 템플릿 바인딩 — LLM 최소화 |

> ⚠️ 구체적 원가는 실제 프롬프트 길이 확정 후 토큰 측정 필요. **현시점 미검증.**
> 목표: **생성 1회 원가 ≤ 판매가의 30%**. 이를 넘으면 크레딧 단가를 올리거나 ③ 이외 단계를 축소.

### 원가 절감 수단

| 수단 | 효과 |
|---|---|
| 단계별 모델 분리 | ①⑤를 소형 모델로 → 큰 절감 |
| 프롬프트 캐싱 | 팩 프롬프트는 사용자 간 동일 → 캐시 적중률 높음 |
| ⑤ 렌더를 코드로 | LLM 호출 자체를 제거 |
| 인기 목적지 결과 재사용 | "홋카이도 4박5일 대중교통" 같은 반복 패턴의 부분 캐싱 |
| 무료 티어 제한 | 무료는 ①②만 실행 (③ 미실행) → 무료 유저 원가 최소화 |

### 고정비 (월, v1 기준 추정)

| 항목 | 추정 |
|---|---|
| 서버/호스팅 | 소규모 (기존 AWS 인스턴스 활용 가능) |
| 도메인/결제 수수료 | 결제액의 약 3% |
| 인건비 | 0 (1인 운영 전제) |

→ **초기 고정비는 거의 0.** 손익분기가 매우 낮다는 것이 이 아이디어의 큰 장점.

## 4. 단위 경제 (Unit Economics)

### 목표 지표

| 지표 | 목표 | 근거 |
|---|---|---|
| 생성 1회 매출 | ₩9,900 | v0 가격안 |
| 생성 1회 변동원가 | ≤ ₩3,000 | LLM + 결제수수료 |
| 기여이익률 | ≥ 70% | |
| 무료→유료 전환율 | 5~10% | 미검증 가정 |
| CAC | ₩0 (초기 오가닉) | 광고 미집행 |
| 1인당 연 생성 횟수 | 1.5회 | **최대 약점** |
| LTV (여행 단독) | ₩10,000~20,000 | 낮음 |

### 문제

LTV가 ₩10,000대라면 **유료 광고를 집행할 수 없다.** 오가닉 유입에 전적으로 의존해야 하고, 이는 성장 속도의 상한이 된다.

### 해법 방향

| 방향 | LTV 개선 |
|---|---|
| 버티컬 확장 (여행 외) | 사용 빈도 자체를 올림 |
| 동행자 공유 → 신규 유입 | CAC를 0으로 유지 |
| **B2B 화이트라벨** | 객단가 20배 이상 |

## 5. B2B / 화이트라벨 (확장 핵심)

| 고객 | 제공 | 가격안 |
|---|---|---|
| 여행 블로거/인플루언서 | 자기 브랜드 일정 생성기 (팔로워용) | 월 ₩100,000~ |
| 소규모 여행사 | 상담 초안 자동 생성 도구 | 월 ₩300,000~ |
| 온천 료칸 / 지역 관광협회 | "우리 지역 포함 일정" 생성기 (송객 목적) | 월 정액 또는 송객당 |

**료칸/관광협회는 특히 흥미롭다.** 노보리베츠 료칸 입장에서, "삿포로 여행객이 마지막 밤을 우리 온천에서 보내는 일정"을 자동 제안하는 도구는 **마케팅 비용**이지 소프트웨어 비용이 아니다 → 지불 의사가 다른 차원.

| v2+ | + 팩 마켓플레이스 수수료 | 크리에이터 유입 |
