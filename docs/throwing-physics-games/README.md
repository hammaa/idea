# 던지기·받기 물리 게임 (Throwing & Catching Physics Games)

> **손에서 떠난 물체의 물리를 제대로 다루는 게임 묶음.**
> 소재는 다르지만 만드는 것은 하나 — **떠나 있는 동안 무슨 일이 일어나는지를 정확히 계산하는 엔진.**

| 항목 | 내용 |
|---|---|
| 등록일 | 2026-09-01 |
| 상태 | 🔨 **우산 던지기 작업 중** (2026-09-02) · 나머지 소재는 씨앗 |
| 원안 | 우산 던지기 · 도끼 무게중심 이동 · 부메랑 저글링 · 귤 · 공 던져 벽 튕겨 받기 |
| 추가 | **켄다마** (망치 모양 몸통에 공 올리기) — 2026-09-02 |

> ⚠️ **켄다마가 들어오면서 묶음의 범위가 「던지기」보다 넓어졌다.**
> 켄다마의 공은 끈에 매달려 있어 자유낙하가 아니고, 조작의 주인공도 던지기가 아니라 **받기**다.
> 그래서 이 묶음의 실체는 **「손에서 떠난 물체를 다루는 물리」** — 던지기·받기·매달기를 포함한다.
> *(디렉토리명은 `throwing-physics-games` 그대로 둔다 — 링크를 깨지 않기 위해)*

## 소재 5종 — 각각 물리의 다른 축이 주인공이다

**같은 "던지기"인데 지배하는 물리가 전부 다르다.** 그게 이 묶음의 가치다 — 하나의 엔진으로 다섯 개의 다른 게임이 나온다.

| 소재 | 지배하는 물리 | 게임이 되는 지점 |
|---|---|---|
| **우산** | **공기저항이 중력과 맞먹는다.** 펼침/접힘에 따라 항력계수가 급변 | 던지기 게임 중 유일하게 **공기역학이 주인공**. 펴고 접는 타이밍이 조작 축 |
| **도끼** | **무게중심이 기하중심과 다르다** (편심). 회전축이 자루가 아니라 머리 쪽 | **회전수를 거리에 맞추는 것**. 한 바퀴 반? 두 바퀴 반? |
| **부메랑** | **자이로스코프 세차 + 양력 비대칭** → 돌아온다 | **여러 개를 연속으로 던져 저글링** = 위상(phase) 관리 게임 |
| **귤** | **불규칙 형상 + 무름(변형·터짐)** | 예측 불가성 자체가 재미. 정밀 조준의 반대편 |
| **공 → 벽 → 받기** | **반발계수 + 스핀-벽 상호작용** | ⭐ 핵심 설계 질문 → [01-가상의-벽.md](01-가상의-벽.md) |
| **켄다마** | **끈에 매달린 구속 진자 + 스핀 제거** | 유일하게 **자유낙하가 아니다.** 조작의 주인공이 던지기가 아니라 **받기** |

> **던지기 자체는 포물선이라 쉽다. 어려운 건 물체마다 다른 「손을 떠난 뒤의 사건」이다.**
> 우산은 항력, 도끼는 편심 회전, 부메랑은 세차, 귤은 변형, 공은 충돌, 켄다마는 구속과 받기.
> **여섯 개를 한 엔진에 넣으면 그 엔진이 곧 자산이 된다.**

### 켄다마가 특히 다른 이유

**망치 모양 몸통(켄)에 큰 접시·작은 접시가 달려 있고, 끈에 매달린 공(다마)을 올리거나 받는다.**

| | 나머지 다섯 | **켄다마** |
|---|---|---|
| 물체 | 자유낙하 | **끈에 매달린 구속 진자** |
| 조작 | 던지는 순간 | **받는 순간** (그리고 손목으로 계를 계속 흔든다) |
| 실패 원인 | 조준·세기 | **공이 돌아서** — 다마가 회전하면 접시에 못 얹힌다 |
| 기술의 핵심 | 궤적 설계 | **소프트 캐치** — 받는 순간 상대속도를 0으로 만들기 |

> **"공의 회전을 죽이는 것"이 기술의 절반이다.** 이건 3쿠션에서 다룬 **스핀 감쇠**와 같은 축이고,
> **"받는 순간 상대속도 0"** 은 공-벽 게임의 받기와 같은 문제다.
> **엔진이 이미 갖고 있어야 할 것들이라 추가 비용이 작다.**

*(참고: 한국에서는 죽방울로도 불리나, 엄밀히 죽방울은 디아볼로에 대응한다는 지적이 있다.)*

## ⭐ 3cushions와 물리 코어를 공유한다

[3쿠션 해법기](../billiards-3cushion-solver/) 프로젝트에서 이미 만들기로 한 것들이 그대로 재사용된다.

| 3cushions에서 | 던지기 게임에서 |
|---|---|
| 이벤트 기반 해석적 솔버 (결정론) | 그대로 |
| 반발계수 · 마찰 3종 (미끄럼·구름·스핀) | 벽 충돌 · 지면 착지에 그대로 |
| 회전이 충돌 결과를 바꾸는 모델 | 스핀 먹인 공이 벽에서 튀는 각 |
| **장비 = 실제 물리 파라미터** (pay-to-win 불가) | 우산 크기, 도끼 무게배분, 부메랑 날개각 |
| **테이블 캘리브레이션** | **가상의 벽 캘리브레이션** — 구조가 동일하다 |

> **같은 코어 위에 소재만 바꿔 얹는 구조.** 3cushions가 P1(물리 솔버)에서 만드는 것이
> 여기서 그대로 재사용되므로, **두 프로젝트는 순서를 정해 하나의 엔진을 나눠 쓰는 게 맞다.**
