# 12. 포인트 표기법 — 프레임 점 1칸 = 10 포인트

> **사용자 제안 (2026-08-31):** *"다이아 대신에 많이 쓰는 프레임 점 하나에 10 포인트로 해서 세분화하면 어떨까. 일반적으로 3쿠션에서 하는 것처럼."*
>
> **확인 결과: 맞다. 그게 3쿠션의 표준 표기다.** 목업을 이 눈금으로 바꿨다.

---

## 1. 확인한 것 — 일반 포인트 표기

> **"쓰리쿠션에서는 1포인트 = 10, 2포인트 = 20, 3포인트 = 30으로 읽힌다."**

즉 **레일(프레임)의 점 한 칸이 10**이고, 반 칸이 5다. 그 아래로 더 쪼개면 1포인트 단위가 된다.

### 국제식 대대에 적용하면

| 항목 | 값 |
|---|---|
| 장쿠션 | **0 – 80 포인트** (프레임 점 8칸 × 10) |
| 단쿠션 | **0 – 40 포인트** (4칸 × 10) |
| 코너 | **0** |
| 프레임 점 1칸 | 10 포인트 = **355.5 mm** |
| **1 포인트** | **35.55 mm** (2844 ÷ 80 = 1422 ÷ 40 — 정사각 격자) |
| 반 칸 | 5 포인트 = 177.75 mm |

> **1포인트는 캐롬 공 지름(61.5mm)의 약 58%다.**
> 공 하나보다 작은 단위라 세분화 눈금으로 적당하다 — 더 쪼개면 사람이 눈으로 못 읽는다.

### 왜 다이아 인덱스(0–8)보다 나은가

| | 다이아 인덱스 | **포인트** |
|---|---|---|
| 표기 | 3.25 다이아 | **32.5 포인트** → 실무에선 **33** |
| 소수점 | 필요 | **거의 불필요** |
| 감도표 | "1팁 = 0.42 다이아" | **"1팁 = 4.2 포인트"** |
| 당구장에서 쓰는 말 | 아님 | **맞음** |

**감도표가 특히 좋아진다.** "1팁 = 4포인트"는 그대로 외워서 테이블에서 쓸 수 있는 형태다 —
[01-기획](01-기획.md) 2절에서 세운 목표("궤적은 못 외워도 1팁 = 몇 포인트는 외워진다")에 정확히 맞는 단위다.

---

## 2. ⚠️ 그런데 시스템 숫자는 이 눈금이 아니다

**위 포인트는 "위치를 읽는 일반 눈금"이고, 시스템별 숫자는 별개의 척도다.**
파이브앤하프의 수구수·1쿠션수·3쿠션수는 **레일마다 간격이 다르고, 균등하지도 않다.**

조사에서 나온 내용 (**출처 1건 — 교차검증 전**):

| 값 | 척도 |
|---|---|
| **수구수 (출발값)** | 코너 = **50**. **장쿠션 쪽으로 한 칸당 −5** (45·40·35·30·25·20) / **단쿠션 쪽으로 한 칸당 +10** (60·70·80) |
| **1쿠션수** | 1~5칸 = **10~50** (한 칸당 10). **5를 넘으면 반 칸당 10** → 60·70·80·90 |
| **3쿠션수 (도착값)** | 한 칸당 **10** (10·20·30) |
| 공식 | **수구수 − 3쿠션수 = 1쿠션수** |
| 빈쿠션 보정 | 두 칸당 **2.5** |
| 당점 가이드 | 수구수 30 이내 **10시 30분 3팁** → 진행할수록 10시 → 9시 30분 → 9시 |

> **핵심: 수구수는 한 칸당 5, 1쿠션수는 한 칸당 10, 3쿠션수도 한 칸당 10.**
> **세 값이 서로 다른 자로 재는 숫자다.** 이걸 하나로 뭉뚱그리면 시스템이 통째로 틀어진다.
>
> 그리고 [02-설계](02-설계.md) 2절에서 이미 정리한 대로 **데이텀도 갈린다** —
> **수구수·1쿠션수는 당점 기준, 3쿠션수는 공이 쿠션 천에 닿는 부위 기준.**

### 그래서 목업에는 넣지 않았다

[02-설계](02-설계.md) 2절의 원칙 그대로다:

> **다이아몬드 시스템 숫자표는 별도 전사 작업이 필요하다. 추정으로 채우면 안 된다.**
> **이 제품에서 숫자 하나가 틀리면 신뢰가 통째로 무너진다.**

출처 1건으로는 부족하다. **교재 2~3종을 대조하고 당구대에서 검증한 뒤에 넣는다.**
목업에는 **일반 포인트 눈금만** 쓰고, 시스템 척도가 다르다는 경고만 표시했다.

## 3. 목업 반영 (v3)

| 바뀐 곳 | 전 | 후 |
|---|---|---|
| 도면 레일 라벨 | 0–8 / 0–4 | **0–80 / 0–40 포인트** |
| 수구 위치 슬라이더 | 0–4 다이아, 0.25 단위 | **0–40 포인트, 1포인트 단위** |
| 1쿠션 조준점 슬라이더 | 1–7.5 다이아 | **10–75 포인트, 1포인트 단위** |
| 감도표 값 | `5.25 (+0.25)` | **`52.5 (+2.5)`** |
| 헤더 | 1다이아 = 355.5mm | **프레임 점 1칸 = 10 포인트** |
| 도면 설명 | 다이아 눈금 안내 | 포인트 안내 + **시스템 척도는 다르다는 경고** |

**세분화 단위는 1포인트(35.55mm)로 잡았다.** 그보다 잘게 쪼개면 사람이 레일에서 읽을 수 없어
[01-기획](01-기획.md) 2절의 "테이블에서 쓸 수 있어야 한다"는 기준을 벗어난다.

| 순서 | 할 일 |

| 1 | **교재 2~3종 대조** — 수구수·1쿠션수·3쿠션수 전체 표. 위 1건과 일치하는지 |
| 2 | **데이텀 확정** — 어느 값이 당점 기준이고 어느 값이 접촉점 기준인지 ([02-설계](02-설계.md) 2절) |
| 3 | **당구대 검증** — 수구수 50 → 1쿠션 30 → 3쿠션 20 같은 기준선을 실제로 쳐서 맞는지 |
| 4 | 목업에 시스템 계산 레이어 추가 + **일반 포인트 눈금과 나란히 표시** |

> **3번이 이 아이디어의 강점이 발휘되는 지점이다** — 당구대에 가면 몇 시간 만에 검증된다
> ([01-기획](01-기획.md) 5절의 자체 검증 가능성).
