## 핀토이 = 차이니즈 체커 / 다이아몬드 게임 계열 ✅

> *"별모양 판에 핀을 꽂아서, 반대편으로 한 칸 또는 하나의 핀을 넘어서 연속으로 위치 이동"*

**정체가 확인됐다.** 다윗의 별(육각별) 모양 판을 쓰는 고전 추상전략 게임이다.

| 항목 | 차이니즈 체커 | 다이아몬드 게임 |
|---|---|---|
| 판 | 육각별 (다윗의 별) | 같은 모양, **크기가 더 작다** |
| 인원 | **2~6인** | 2~3인 |
| 말 | 각 진영 | **10개** |
| 시작 배치 | 2인이면 **180° 반대편** | 2인이면 **중심 기준 120°** |
| 이동 | 인접 한 칸 | 같음 |
| 점프 | 말 하나를 뛰어넘기, **연속 가능** | 같음 |
| 승리 | 내 말 전부를 **맞은편 진영**에 넣기 | 같음 |

**규칙은 공개 도메인이다** — 자유롭게 구현할 수 있다.

### ⭐ 이 게임이 이 묶음에 어울리는 이유

| 조건 ([아래 5조건](#이-장르의-핵심-조건)) | 핀토이 |
|---|:-:|
| 규칙은 5분 | ✅ **두 줄이면 끝난다** (한 칸 or 점프) |
| 전략은 안 끝난다 | ✅ **연속 점프 사슬 설계**가 사실상 무한 |
| 선택이 공개된다 | ✅ 판이 전부 보인다 |
| 3~6인 배신·협력 | ✅ **2~6인** — [미해결 2번](#미해결-질문)의 답이 여기 있다 |
| 한 판이 짧다 | ❌ **원안과 충돌한다** — 말 10개를 다 옮겨야 끝난다 |

### 그리고 여기에 진짜 심리전이 있다

> **상대의 말이 내 징검다리가 된다.**
> 연속 점프는 남의 말을 밟고 가는 것이라, **상대를 막으면 내 길도 막힌다.**
> 길을 열어 주면서 내가 더 이득을 보는 배치를 찾는 것 — **적대적 협력**이다.
>
> **"규칙은 단순한데 전략이 깊다"의 교과서적 사례**이고, 이 묶음이 노리는 성질 그대로다.

## 축이 둘로 갈린다

원안 4개는 하나의 축이 아니라 **두 축**이다. 묶을 때 이걸 인정하고 묶어야 한다.

### 축 A — 공간 점유 (땅먹기 · 지반붕괴 · 명당 만들기)

| | 땅먹기 | 지반붕괴 | 명당 만들기 |
|---|---|---|---|
| 자원 | **공간** | **공간** | **공간** |
| 방향 | 늘린다 | **줄어든다** | 고른다 |
| 승리 | 많이 먹기 | 오래 버티기 | 잘 고르기 |
| 심리 | 남의 확장을 막기 | **남을 무너지게 유도** | 남이 안 갈 곳 예측 |

> 셋 다 "공간을 두고 벌이는 심리전"이고 방향만 다르다.
> **하나의 보드 엔진 위에 규칙만 바꿔 얹을 수 있다.**

### 축 B — 경주 · 경로 설계 (핀토이)

공간을 **뺏는** 게 아니라 **통과하는** 게임이다. 상대 말은 장애물이자 발판이다.

> **축이 다르다는 것은 약점이 아니라 장점이다.**
> 모음집이라면 **점유 게임 3종 + 경주 게임 1종**이 같은 것 4개보다 낫다.
> 다만 **엔진은 공유되지 않는다** — 축 A는 영역 계산, 축 B는 그래프 경로 탐색이다.

## 이 장르의 핵심 조건

「지니어스」·「데블스 플랜」이 재미있는 이유는 게임이 복잡해서가 아니다.

| 조건 | 내용 |
|---|---|
| **규칙은 5분** | 설명이 길면 그 자리에서 죽는다 |
| **전략은 안 끝난다** | 규칙이 단순한데 최적해가 안 보여야 한다 |
| **선택이 공개된다** | 남의 수가 보여야 심리전이 생긴다 |
| **한 판이 짧다** | 져도 바로 다시. 원안의 "짧게 끝나기"가 정확히 이것 |
| **배신·협력이 가능** | 2인 대전보다 **3~6인**에서 살아난다 |

> ⚠️ **가장 어려운 건 게임 디자인이 아니라 「규칙은 단순한데 전략이 깊은」 균형점 찾기다.**
> 그건 문서로 못 만들고 **종이로 만들어 사람과 쳐 봐야 나온다.**
