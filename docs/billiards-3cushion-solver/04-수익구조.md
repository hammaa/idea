# 04. 수익 구조 — 무료 경쟁자가 있는 시장에서

조사일 2026-08-30

---

## 1. 가격 앵커 — 이미 정해져 있다

| 경쟁자 | 가격 | 시장에 주는 신호 |
|---|---|---|
| **3ball.app** | **무료** (계정·페이월 없음, 선택적 광고) | **가격 하한이 0** |
| **Bricole** | $4.99/월 · $39.99/년 · **$89.99 평생** | 유료 상한 시도치. **다만 실적으로 검증되지 않음** |

> **가격을 우리가 정할 수 없다.** 3ball이 무료인 이상,
> **유료 구간은 "3ball이 안 하는 것"에만 매길 수 있다.**

그리고 3ball이 안 하는 것 = **팁 감도표 + 괴리 진단 + 테이블 보정 축적** ([01-기획](01-기획.md) 2절).

---

## 2. B2C 경로

| 모델 | 내용 | 평가 |
|---|---|---|
| **프리미엄(Freemium)** | 궤적·시스템 계산은 무료(3ball과 동급), **감도표·괴리 진단·개인 캘리브레이션은 유료** | ✅ 유일하게 성립 가능한 형태 |
| 구독 | 월 4,900원 / 연 39,000원 수준 (Bricole 앵커 참고) | ⚠️ 학습 도구는 목표 달성 후 이탈 → **구독 유지가 어려움** |
| 평생 결제 | 89,000원대 | ⚠️ 이탈 문제를 우회하나 **LTV가 1회로 끝남** |
| 광고 | 3ball이 이미 함 | ❌ 이 규모의 트래픽으로는 무의미 |

> **구독의 구조적 약점:** 시스템 학습은 **끝이 있는 과업**이다.
> 파이브앤하프를 익히고 나면 앱을 계속 결제할 이유가 사라진다.
> → **구독을 성립시키려면 "끝나지 않는 것"이 필요하다** = 드릴·랭킹·기록, 또는 **테이블별 보정**(장소가 바뀌면 다시 필요).

---

## 3. B2B 경로

| 대상 | 제안 | 지불 여력 | 평가 |
|---|---|:-:|---|
| **당구장** (2만~2만5천 개) | 테이블별 보정 데이터 + 태블릿 비치 + 손님 유치용 콘텐츠 | 낮음 | ⚠️ 당구장은 3중고를 겪는 업종으로 보도됨. **신규 지출 여력 의심** |
| **레슨 코치** | 학생 진단 도구 — "이 학생은 3팁에서 항상 짧다" | 중 | ✅ **가장 현실적.** 코치는 도구에 돈을 쓴다 |
| **PBA / 연맹 / 클럽** | 공식 학습 도구 제휴, 대회 분석 | 중 | ❓ 접점 필요 |
| **큐 제조사** | 스쿼트는 **샤프트 끝단 질량**에 좌우 → 저디플렉션 샤프트 마케팅과 직결 | 중 | ⭐ **의외의 접점.** "우리 샤프트는 피벗 길이가 얼마" 를 수치로 보여주는 도구 |

> **큐 제조사 각도가 흥미롭다.** 스쿼트 계산 엔진은 **장비의 성능 차이를 정량화**한다.
> 이건 소비자에게 파는 것보다 **장비 업계에 파는 것**이 더 쉬울 수 있다.

---

## 4. ⭐ 유일한 해자 후보 — 테이블 보정 데이터베이스

다이아몬드 시스템의 최대 약점은 **테이블마다 반발이 다르다**는 것이다.
캘리브레이션은 그래서 필수 기능이고([02-설계](02-설계.md) 6절), **그 결과를 장소 단위로 축적하면 성격이 달라진다.**

```
사용자 A가 강남 ○○당구장 3번 테이블을 캘리브레이션
          ↓
사용자 B가 같은 테이블에 가면  →  이미 보정값이 있다
          ↓
"이 테이블은 평균보다 짧게 튑니다 (−1.2포인트)"
```

| 성질 | 내용 |
|---|---|
| **복제 불가** | 경쟁자가 코드로 따라올 수 없다. **사용자가 있어야만 생긴다** |
| 네트워크 효과 | 사용자가 늘수록 커버되는 테이블이 늘고, 그럴수록 유용해진다 |
| 지역 밀착 | 전국 2만 5천 개 당구장 = **한국이 세계 최다 보유국**이라는 조건과 정확히 맞물림 |
| 구독 정당화 | 장소가 바뀌면 다시 필요 → **끝나지 않는 가치** |

> **이게 이 아이디어에서 유일하게 "시간이 지날수록 강해지는" 자산이다.**
> 물리 엔진도, 시스템 공식도, 궤적 렌더링도 전부 복제 가능하다. **이것만 아니다.**

⚠️ **다만 닭과 달걀이다.** 데이터가 쌓이려면 사용자가 필요하고, 사용자를 모으려면 가치가 있어야 한다.
**초기 부트스트랩(직접 주요 당구장을 돌며 캘리브레이션)이 필요하고, 그건 노동집약적이다.**

## 5. 수익 구조 종합

| 단계 | 형태 | 조건 |
|---|---|---|
| **v0** | **무료** — 지불 의사 확인이 목적. 감도표까지 전부 공개 | 사용자 확보가 먼저 |
| v1 | 프리미엄 — 개인 캘리브레이션·괴리 진단·기록을 유료화 | v0에서 **재방문율**이 나와야 함 |
| v2 | 테이블 DB 구독 (장소 커버리지가 가치) | 데이터 임계량 필요 |
| v2' | B2B — 코치용 진단 도구, 큐 제조사 제휴 | B2C가 실패해도 살아남을 수 있는 경로 |

> **v0을 유료로 시작하면 안 된다.** Bricole이 그렇게 했고, 평점이 쌓이지 않았다.

---

## 6. 냉정한 결론

| 질문 | 답 |
|---|---|
| 가격을 정할 수 있나 | ❌ 무료 경쟁자가 상한을 누른다 |
| 구독이 유지되나 | ⚠️ 학습은 끝이 있다. **테이블 DB 없이는 어렵다** |
| B2C로 성립하나 | ❓ Bricole 실적이 부정적 신호 |
| B2B로 성립하나 | ⚠️ 코치·큐 제조사 각도는 미탐색. **여기가 더 유망할 수 있다** |
| **시간이 지날수록 강해지는 게 있나** | ✅ **테이블 보정 데이터베이스, 그것 하나** |
