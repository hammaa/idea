# 짧은 네트워크 대전 게임 (Quick-Match Party Games)

> **한 판이 짧게 끝나는 네트워크 대전 모음.**
> 규칙은 5분에 배우고, 전략은 안 끝나는 것 — 「지니어스」·「데블스 플랜」 계열.

| 항목 | 내용 |
|---|---|
| 등록일 | 2026-09-01 |
| 상태 | 🌱 **아이디어 씨앗** (소재 4종, 조사 전) |
| 원안 | 핀토이 네트워크 대전 · 짧게 끝나는 간단 게임들 · 데스게임식 심리전 (땅먹기, 지반붕괴, 명당 만들기) |

---

## 소재

| 소재 | 성격 | 상태 |
|---|---|:-:|
| **핀토이** | 네트워크 대전 | ❓ **확인 필요** — 검색으로 정체를 찾지 못했다. 핀볼 계열인지, 특정 게임 이름인지, 다른 표기인지 확인 필요 |
| **땅먹기** | 영역 점유 | 🌱 원안 |
| **지반붕괴** | 영역 **상실** — 밟은 자리가 무너진다 | 🌱 원안 |
| **명당 만들기** | 위치 선점 + 가치 변동 | 🌱 원안 |

### 세 개가 사실 하나의 축 위에 있다

| | 땅먹기 | 지반붕괴 | 명당 만들기 |
|---|---|---|---|
| 자원 | **공간** | **공간** | **공간** |
| 방향 | 늘린다 | **줄어든다** | 고른다 |
| 승리 | 많이 먹기 | 오래 버티기 | 잘 고르기 |
| 심리 | 남의 확장을 막기 | **남을 무너지게 유도** | 남이 안 갈 곳 예측 |

> **셋 다 "공간을 두고 벌이는 심리전"이고, 방향만 다르다.**
> **하나의 보드 엔진 위에 규칙만 바꿔 얹을 수 있다** — 던지기 게임 묶음과 같은 구조다.

---

## 이 장르의 핵심 조건

「지니어스」·「데블스 플랜」이 재미있는 이유는 게임이 복잡해서가 아니다.

| 조건 | 내용 |
|---|---|
| **규칙은 5분** | 설명이 길면 그 자리에서 죽는다 |
| **전략은 안 끝난다** | 규칙이 단순한데 최적해가 안 보여야 한다 |
| **선택이 공개된다** | 남의 수가 보여야 심리전이 생긴다 |
| **한 판이 짧다** | 져도 바로 다시. 원안의 "짧게 끝나기"가 정확히 이것 |
| **배신·협력이 가능** | 2인 대전보다 **3~6인**에서 살아난다 |

> ⚠️ **가장 어려운 건 게임 디자인이 아니라 「규칙은 단순한데 전략이 깊은」 균형점 찾기다.**
> 그건 문서로 못 만들고 **종이로 만들어 사람과 쳐 봐야 나온다.**

## 미해결 질문

| # | 질문 | 왜 중요한가 |
|:-:|---|---|
| **1** | **핀토이가 무엇인가** | 소재 4개 중 하나가 정체 불명이다 |
| **2** | **몇 인 대전인가** | 2인이면 순수 전략, 3인 이상이면 **배신·연합**이 들어온다. 장르가 완전히 달라진다 |
| **3** | **동시 진행인가 턴제인가** | 짧게 끝나려면 동시 진행이 유리하고, 심리전은 턴제가 깊다 |
| 4 | 실시간 매칭인가 비동기인가 | 짧은 판은 매칭 대기가 더 길어질 수 있다 |
| 5 | 모여서 하는가(같은 방) 온라인인가 | 배신 게임은 얼굴이 보일 때 훨씬 재미있다 |

> **2번이 블로커다.** 인원수가 정해져야 나머지 설계가 시작된다.
