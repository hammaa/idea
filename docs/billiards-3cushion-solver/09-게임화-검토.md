# 09. 게임화 검토 — Unity 3D 1인칭 시뮬레이션

> **원안 전환 (2026-08-30):** 계산 도구가 아니라 **Unity 3D로 실제 당구 치듯 하는 게임**으로.
> 큐 아이템·팁 튜닝, 큐 들고 각 재기, 자리잡고 시선 처리, 낮게 앉아 두께 확인,
> 1인칭 당점·두께 조정, **백스윙 동작으로 스트로크 타입 판정**, 강약은 드래그로.
>
> ⚠️ **이 전환은 [01-기획](01-기획.md) 3절의 "게임 플레이는 v0에서 뺀다" 결정을 뒤집는다.**
> 그래서 그 결정의 근거가 아직 유효한지부터 다시 확인했다.

## 1. ⚠️ 먼저 — 이것도 이미 있다. 그리고 또 안 됐다.

### 3Cushion Masters (Steam, 2021-07-18, F2P)

| 항목 | 내용 |
|---|---|
| 종목 | **3쿠션 전문** (1쿠션·4구·6구·NCarom·서바이벌 포함 6종) |
| 시점 | **1인칭 지원** |

| **큐 시스템** | **실존 큐를 구매하거나 승점으로 획득, 큐 관리** + 천 색·우드·공까지 구매 |
| 가격 | 무료 (F2P + 인앱결제) |
| 온라인 | PvP, 협동 |
| **평가** | **리뷰 142개 · 긍정 50%** |

> **원안의 게임 요소 대부분이 이미 구현되어 있다** — 1인칭, 스쿼트, 테이블 마찰, 큐 구매·관리, F2P.
> **그리고 출시 4년이 넘도록 리뷰 142개, 긍정 50%다.**

게임 시장은 도구 시장보다 크지만, **3쿠션 게임 시장은 도구 시장만큼 작다.**

## 2. 그래도 원안에 없던 것이 있다 — 몸으로 하는 조준

3Cushion Masters의 조작은 **"터치 컨트롤 기반 스틱 이동"** 이다. 관습적인 조준 UI다.
원안이 요구한 것은 다르다.

| 원안 요구 | 기존 게임 | 판정 |
|---|---|:-:|
| 1인칭 시점 | ✅ 3Cushion Masters 지원 | 차별점 없음 |
| 스쿼트 재현 | ✅ 3Cushion Masters 언급 | 차별점 없음 |
| 큐 아이템·구매 | ✅ 3Cushion Masters 있음 | **형태는 같으나 내용이 다름 → 4절** |
| **큐대 들고 각 재는 동작** | ❌ 확인 안 됨 | ⭐ **신규** |
| **자리잡기 · 시선 처리** | ❌ 확인 안 됨 | ⭐ **신규** |
| **낮게 앉아 두께 확인** | ❌ 확인 안 됨 | ⭐ **신규** |
| **백스윙 동작으로 스트로크 타입 판정** | ❌ 확인 안 됨 | ⭐ **신규** |
| 팁 튜닝 | ❌ 확인 안 됨 | ⭐ **신규** |

### VR은 이미 몸을 쓴다 — 다만 정밀도를 포기했다

| 게임 | 방식 |
|---|---|

| [Sports Bar VR](https://store.steampowered.com/app/269170/Sports_Bar_VR/) | 최대 8인 가상 스포츠바. 풀 시뮬레이션 |

> **VR 당구는 몸을 쓰지만 "조준 보조 + 손목 스냅"이라 정밀 시뮬레이션이 아니다.**
> **그리고 둘 다 포켓볼이지 캐롬이 아니다.**
>
> **⇒ 「몸으로 하는 조준 절차를 정밀하게 구현한 캐롬 게임」은 실제로 비어 있다.**

⚠️ **다만 비어 있는 데는 이유가 있을 수 있다.** 자리잡고 각 재고 낮게 앉는 절차는
**현실에서는 몰입이지만 화면에서는 지루한 단계**가 되기 쉽다. 이건 만들어 봐야 아는 종류의 위험이다.

## 3. 개발 규모 — 이전 계획과 자릿수가 다르다

| | 계산 도구 (v0) | **Unity 3D 1인칭 게임** |
|---|---|---|
| 물리 | 오픈소스 엔진 + 파라미터 | **커스텀 솔버 필수** (→ [10-게임설계](10-게임-설계.md) 2절) |
| 렌더링 | SVG 도면 | 3D 씬, 조명, 재질, 애니메이션 |
| 조작 | 슬라이더 | **1인칭 6단계 조준 시퀀스** |
| 콘텐츠 | 없음 | 장비·튜토리얼·모드·진행 |
| 온라인 | 없음 | 매칭·동기화·랭킹 |
| **규모** | **1인 2~3개월** | **소규모 팀 1~2년** |

> **"게임처럼 쳐도 되고"는 원안 7개 중 개발비가 가장 큰 항목이었다** ([01-기획](01-기획.md) 3절).
> 그 판단은 지금도 맞고, 요구가 1인칭 몸동작까지 확장되면서 **더 커졌다.**

## 4. ⭐ 그런데 이 전환에서 진짜로 강한 아이디어가 하나 나온다

원안의 **"큐대 아이템으로 더 좋은 성능, 팁도 고급으로 튜닝"** 을 그대로 만들면 흔한 pay-to-win이다.
**그런데 이 프로젝트에는 그걸 다르게 만들 재료가 이미 있다.**

### 장비 스탯을 지어내지 않고, 실제 물리 파라미터를 그대로 쓴다

| 게임 안 아이템 | 흔한 구현 | **이 프로젝트의 구현** |
|---|---|---|
| 큐 | "정확도 +5" 같은 가짜 스탯 | **자연 피벗 길이 (인치)** → 스쿼트각을 직접 결정 |
| 팁 | "파워 +3" | **미스큐 한계 오프셋**, 마찰 계수 |
| 초크 | 소모품 | 팁-공 마찰 |
| 천 / 테이블 | 스킨 | **μs · μr · 쿠션 반발 곡선** |

### 그리고 여기서 나오는 결론이 이 게임의 정체성이다

> **[07번](07-거리-속도-마찰-모델.md) 3절에서 이미 실증했다 — 저디플렉션 큐는 무조건 좋은 큐가 아니다.**
> 스쿼트가 작아지면 커브가 상쇄할 상대를 잃어, **느린 롱샷에서 회전 준 쪽으로 과보정**한다.

```
목재 9.5"   : 어떤 속도·거리에서도 회전 반대쪽 (예측 가능, 보정량이 큼)
저디플렉션 19": 느린 롱샷에서 부호가 뒤집힘 (보정량은 작지만 구간마다 부호가 다름)
```

> ### **"더 좋은 큐"가 존재하지 않는다. 거리·속도 대역마다 유리한 큐가 다르다.**

| 이것이 만드는 것 | |
|---|---|
| **pay-to-win이 구조적으로 불가능** | 비싼 큐가 모든 상황에서 유리하지 않다 — **물리가 그렇게 되어 있어서** |
| **진짜 빌드/로드아웃 깊이** | 배치 성향에 따라 큐를 고른다. 숫자 밸런싱이 아니라 물리에서 나옴 |
| **복제 난이도** | 이걸 흉내내려면 [06](06-입력-파라미터-모델.md)·[07번](07-거리-속도-마찰-모델.md)의 모델을 다시 해야 한다 |
| **학습이 곧 실력** | 게임에서 배운 것이 **실제 당구대에서 그대로 통한다** |

**이건 3Cushion Masters의 "실존 큐 구매"와 이름만 같고 내용이 완전히 다르다.**

| [감도 데모](mockup/) 감도표·괴리 진단 | **리플레이 분석 화면** — "당신은 3팁에서 항상 짧다" |
| [08번](08-AX-설계.md) AI 해설 | **인게임 코치** — 1인칭이 어려워 좌절하는 것을 막는 장치 |

> **게임은 유통 채널이고, 물리 정확도가 차별점이고, 분석 계층이 리텐션이다.**
> 앞의 8개 문서가 전부 이 구조 안에 들어간다.

## 6. 판정

| 축 | 도구 (v0) | **게임** |
|---|:-:|:-:|
| 개발 규모 | 1인 2~3개월 | **팀 1~2년** |
| 시장 크기 | 작음 | **더 크지만 3쿠션 한정이면 여전히 작음** |
| 경쟁 | 2건, 결손 확인 | **3건째, 1인칭·스쿼트·큐아이템 이미 있음** |
| 차별점 | 물리 정확도 | **몸으로 하는 조준 + 물리 기반 장비** |
| 리텐션 | 약함 (학습은 끝이 있음) | **강함 (게임은 리텐션이 내장)** |
| 수익모델 | 미검증 | **F2P+IAP, 검증된 모델** |
| **위험** | 안 팔릴 위험 | **안 팔리는데 개발비가 10배** |

### 결론 — 방향은 맞지만 순서가 틀렸다

> **게임화는 리텐션과 수익모델 문제를 실제로 해결한다.** 도구가 못 푸는 걸 게임은 푼다.
> **그러나 3Cushion Masters가 리뷰 142개·긍정 50%라는 사실은 "게임으로 만들면 된다"를 반증한다.**
>
> **그리고 결정적으로 — 게임이든 도구든 검증해야 할 것은 같다.**
> **"이 물리 정확도에 사람이 반응하는가."**
> 그건 1~2년짜리 게임을 만들어서 확인할 일이 아니다.

### 권고

| 순서 | 할 일 | 규모 |
|:-:|---|---|
| **1** | **[감도 데모](mockup/)로 지불 의사·반응 확인** | 이미 만들어져 있음. 묻기만 하면 됨 |
| **2** | **3Cushion Masters를 직접 해 본다** — 1인칭이 실제로 어떤지, 50% 부정 리뷰의 이유가 무엇인지 | 무료. 하루 |
| **3** | **Unity 물리 프로토타입 1개** — 씬도 UI도 없이, **공 3개 + 커스텀 솔버 + 스쿼트/커브만.** 실제 당구대 결과와 대조 | 2~4주 |
| **4** | **1인칭 조준 시퀀스 프로토타입** — 자리잡기·각 재기·백스윙 판정만. **재미있는지 아니면 지루한지 확인** | 2~4주 |
| — | 게임 본편 | **1~4 전에는 하지 않는다** |

> **3번과 4번이 이 전환의 진짜 두 리스크다.**
> **3번은 "정확하게 만들 수 있는가", 4번은 "정확한 게 재미있는가".**
> **둘 다 한 달짜리로 답이 나오고, 둘 중 하나라도 아니면 1~2년을 아낀다.**
