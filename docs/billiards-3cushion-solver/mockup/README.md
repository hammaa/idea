## 설계 원칙 — 숫자마다 신뢰도를 표시한다

화면의 모든 값에 **계산 / 실측 / 미확정** 배지를 붙였다.
이건 장식이 아니라 [08-AX-설계](../08-AX-설계.md) 2절의 **"AI는 숫자를 만들지 않는다"** 원칙을 화면으로 옮긴 것이다.

| 배지 | 의미 | 이 화면에서 |
|---|---|---|
| **계산** | 확정된 공식으로 실시간 계산 | 두께↔절단각 `sinθ=1−f` · 스쿼트각 `tanθ=오프셋/피벗` · **당점→오버스핀 `ω/v=5b/2R²`** · **미스큐 한계 `\|b\|≤R/2`** · 미끄럼 전이 `d=(2v²/7μg)(\|1−s\|−(1−s)²/7)` · **8쿠션 기하 반사 경로** · 90°/30° 법칙 |
| **실측** | 문헌 실측값을 가져다 씀 | 피벗 길이 9.5"/13"/19" (**풀 기준** — 캐롬은 재측정 필요) · 쿠션 반발계수 0.818 · **팁 접촉 시간 약 0.001초 — 팔로우스루는 공에 직접 영향을 주지 못한다** |
| **미확정** | 당구대에서 재야 확정 | 커브 계수 `C` · **회전 감쇠율 (미끄럼 0.35/m · 구름 0.06/m · 쿠션당 75%)** · 회전의 쿠션 반발 효과 · 구름 저항 · 팁→mm 환산 · **다이아몬드 시스템 숫자표** |

> **경쟁 서비스는 모든 숫자를 똑같은 확신으로 보여준다. 이 화면은 무엇을 아직 모르는지 표시한다.**
> 그게 "괴리 진단기"라는 제품 정의의 화면판이다.

## 커브 모델에 대한 정직한 고지

히트맵의 순 이탈량은 다음 모델을 쓴다. **계수 `C=6.0`은 임의값이고 캘리브레이션 대상이다.**

```
a      = C · sin(큐각도) · (팁/4)                 ← 미끄럼 중 횡가속
t_s    = 2v / (7·μ·g)          d_s = 12v² / (49·μ·g)
Δφ     = atan( 2a / (7·μ·g) )                     ← 속도에 무관한 각도 변화
커브   = d ≤ d_s ? ½·a·(d/v)²
                 : ½·a·t_s² + (d − d_s)·tan(Δφ)
순이탈 = 스쿼트 − 커브
```

이 형태를 고른 근거는 **Dr. Dave 실측 결론**이다 — 순수 스쿼트는 속도에 무관하고,
빠른 샷일수록 커브가 지연돼 상쇄가 덜 되므로 **순 이탈량이 커진다.** 위 식이 그 거동을 재현한다:

| 2팁 · 큐각도 3° · μ=0.20 · 거리 2m | v=1.5 | v=2.5 | v=3.5 | v=4.5 | v=5.5 |
|---|---:|---:|---:|---:|---:|
| 목재 9.5" | 39.8 | 44.6 | 51.7 | 67.4 | 72.5 |
| Cuetec 13" | 17.5 | 22.2 | 29.4 | 45.1 | 50.2 |
| **저디플렉션 19"** | **−1.7** | 3.1 | 10.3 | 25.9 | 31.1 |

**저디플렉션 큐만 느린 샷에서 부호가 음수로 넘어간다** — 스쿼트가 작아 커브가 상쇄할 상대를 잃는다.
[07번](../07-거리-속도-마찰-모델.md) 3절에서 지적한 "카본은 스쿼트가 잘 안 나니 커브가 남는다"가 그대로 재현된 것이다.

> **다만 이건 "모델이 관측을 재현한다"이지 "계수가 맞다"가 아니다.** `C`는 당구대에서 재야 한다.

## 좌표계 — 다이아 눈금의 기준

| 것 | 기준 |
|---|---|
| 포인트 눈금 | 장쿠션 **0–80** / 단쿠션 **0–40**, 코너 = 0 |
| 프레임 점 1칸 | **10 포인트 = 355.5 mm** · **1포인트 = 35.55 mm** (2844÷80 = 1422÷40) |
| 다이아 물리 위치 | **레일(프레임) 위**, 쿠션 노즈에서 약 **94 mm** 바깥. 서로 등간격 |
| 표에 찍히는 값 | **공이 쿠션 천에 닿는 지점**을 다이아 눈금으로 읽은 것 |

⚠️ 이건 **기하학적 다이아 인덱스**이지 시스템 숫자가 아니다.
파이브앤하프의 수구수 50·40·30 같은 값은 여기에 시스템별 척도를 다시 입힌 것이고,
시스템 안에서도 **수구수·1쿠션수는 당점 기준 / 3쿠션수는 접촉점 기준**으로 데이텀이 갈린다 ([02-설계](../02-설계.md) 2절).
**목업은 접촉점 하나만 쓴다.**
