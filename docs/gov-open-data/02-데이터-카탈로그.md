# 02. 데이터 카탈로그 — 어떤 정보가 있는가

> 도메인별로 **누가 무엇을 갖고 있고, 어떤 형태로 나오는지** 정리.
> 조사일 2026-08-30. 표의 **형태** 열: `API` 오픈API / `파일` CSV·XLSX 등 다운로드 / `열람` 웹 조회만 / `심사` 신청·승인 필요 / `현장` 지정 장소에서만

---

## 0. 관문 3개 — 여기부터 본다

| 관문 | 무엇 | 특징 |
|---|---|---|
| **[공공데이터포털](https://www.data.go.kr/)** | 전 부처·기관의 개방 데이터 통합 카탈로그 (**10만 건**) | 대부분의 API 키를 여기서 발급. 3단계 이상 개방형식 파일은 **자동으로 오픈API로 변환**해 제공 |
| **[정보공개포털](https://www.open.go.kr/)** | 청구 창구 + **결재문서 원문공개 검색** | 데이터가 아니라 **문서**를 찾는 곳 |
| **[국가중점데이터](https://www.data.go.kr/tcs/eds/selectCoreDataListView.do)** | 고가치로 지정해 집중 개방한 **217종** | 품질·갱신주기가 상대적으로 보장됨. **여기부터 뒤지는 게 효율적** |

> **공공데이터포털에 없다고 없는 게 아니다.** 아래 도메인별 전용 포털이 원본이고, 포털에는 그중 일부만 올라온다.
> 특히 **금융(DART)·법령(law.go.kr)·통계(KOSIS)·의료(HIRA)** 는 전용 시스템이 훨씬 풍부하다.

## 2. 통계 · 인구 · 마이크로데이터

**2025-10-01 통계청이 [국가데이터처](https://mods.go.kr/)로 개편**되었다. 도메인·기관명이 바뀌는 중이므로 링크 확인 필요.

| 무엇 | 어디 | 형태 | 비고 |
|---|---|---|---|
| 국가승인통계 집계표 (**약 1,000종 / 300여 기관**) | **[KOSIS 국가통계포털](https://kosis.kr/)** | API·파일·열람 | 인구·경제·사회·환경 전 분야. 시계열·지역별 |
| **마이크로데이터** (원표본 단위) | **[MDIS](https://mdis.kostat.go.kr/)** | 파일(공공용) / 심사·현장(인가용) | **공공용**: 다운로드·온라인분석 자유 / **인가용**: 세부항목 포함, 원격접근·센터 방문 |
| 통계지리정보 (격자·경계·인구분포) | SGIS+ | API·열람 | 공간 단위 통계 |
| 지표 해설·국제 비교 | 지표누리 | 열람 | |

> 통계청 **ONE-ID** 하나로 MDIS·KOSIS·지표누리·SGIS+를 함께 쓴다.
> **집계표(KOSIS)로 안 풀리는 질문은 대부분 마이크로데이터(MDIS)로 풀린다.** 이 구분이 실무의 핵심이다.

## 12. 행정 · 기관 운영 (주로 ①청구 영역)

**여기가 "공공데이터 개방"으로는 잘 안 나오고 정보공개청구로 나오는 영역이다.**

| 무엇 | 접근 |
|---|---|
| 결재문서 원문 | **정보공개포털 원문공개 검색** — 청구 없이 검색됨 |
| 회의록, 위원회 심의 자료 | ① 청구 |
| 감사·점검 결과, 처분 내역 | ① 청구 (감사원 일부는 공표) |
| 업무추진비, 출장·행사 집행 내역 | ① 청구 (일부 기관은 사전공표) |
| 인허가·신고 접수 현황 | ① 청구 또는 지자체 개방 |
| 민원 통계·처리 내역 | ① 청구 |
| 공무원 인사·정원·조직 | 일부 공표 + ① 청구 |

## 13. 지방자치단체

**과소평가되는 영역.** 지자체는 각자 데이터 포털을 운영하며, 중앙 포털에 없는 생활밀착 데이터가 많다.

| 예 | 비고 |
|---|---|
| 서울 열린데이터광장, 경기데이터드림 등 광역 단위 포털 | 유동인구, 상권, CCTV, 주차장, 공공시설 예약 |
| 인허가 데이터 (LOCALDATA) | **영업 인허가 전국 통합** — 업종별 개폐업 이력. 상권 분석의 표준 재료 |
| 조례·규칙 (자치법규) | open.law.go.kr에서 전국 비교 가능 |
| 지방재정·지방공기업 | 지방재정통합공개, 클린아이 |

> **지자체 데이터는 스키마가 제각각이다.** 17개 시도 × 226개 시군구를 정규화하는 작업 자체가 진입장벽이자 가치다.

## 종합 — 도메인별 개방 성숙도

| 성숙도 | 도메인 | 특징 |
|---|---|---|
| **높음** (API 완비, 즉시 사용) | 재정·조달, 부동산, 기상, 상장사 공시, 법령 | 진입장벽 낮음 = **이미 경쟁 포화** |
| **중간** (있으나 가공 필요) | 통계, 교통, 교육, 노동, 지자체 | 스키마 정규화·결합에 부가가치 여지 |
| **낮음** (심사·현장 접근) | 보건의료 개인단위, 통계 인가용 마이크로데이터, 가명정보 결합 | 진입장벽 = **해자**. 자격·절차가 곧 경쟁력 |
| **닫힘** (유료 또는 비공개) | 법인등기, 부동산 소유권, 비상장 기업 재무, 판결문 전수 | 제도가 바뀌지 않으면 안 열림 |
