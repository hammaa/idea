## 소재 5종 — 각각 물리의 다른 축이 주인공이다

**같은 "던지기"인데 지배하는 물리가 전부 다르다.** 그게 이 묶음의 가치다 — 하나의 엔진으로 다섯 개의 다른 게임이 나온다.

| 소재 | 지배하는 물리 | 게임이 되는 지점 |
|---|---|---|
| **우산** | **공기저항이 중력과 맞먹는다.** 펼침/접힘에 따라 항력계수가 급변 | 던지기 게임 중 유일하게 **공기역학이 주인공**. 펴고 접는 타이밍이 조작 축 |
| **도끼** | **무게중심이 기하중심과 다르다** (편심). 회전축이 자루가 아니라 머리 쪽 | **회전수를 거리에 맞추는 것**. 한 바퀴 반? 두 바퀴 반? |
| **부메랑** | **자이로스코프 세차 + 양력 비대칭** → 돌아온다 | **여러 개를 연속으로 던져 저글링** = 위상(phase) 관리 게임 |
| **귤** | **불규칙 형상 + 무름(변형·터짐)** | 예측 불가성 자체가 재미. 정밀 조준의 반대편 |
| **공 → 벽 → 받기** | **반발계수 + 스핀-벽 상호작용** | ⭐ 핵심 설계 질문 → [01-가상의-벽.md](01-가상의-벽.md) |

> **던지기 자체는 포물선이라 쉽다. 어려운 건 물체마다 다른 「날아가는 중의 사건」이다.**
> 우산은 항력, 도끼는 편심 회전, 부메랑은 세차, 귤은 변형, 공은 충돌.
> **다섯 개를 한 엔진에 넣으면 그 엔진이 곧 자산이 된다.**

## ⭐ 3cushions와 물리 코어를 공유한다

[3쿠션 해법기](../billiards-3cushion-solver/) 프로젝트에서 이미 만들기로 한 것들이 그대로 재사용된다.

| 3cushions에서 | 던지기 게임에서 |
|---|---|
| 이벤트 기반 해석적 솔버 (결정론) | 그대로 |
| 반발계수 · 마찰 3종 (미끄럼·구름·스핀) | 벽 충돌 · 지면 착지에 그대로 |
| 회전이 충돌 결과를 바꾸는 모델 | 스핀 먹인 공이 벽에서 튀는 각 |
| **장비 = 실제 물리 파라미터** (pay-to-win 불가) | 우산 크기, 도끼 무게배분, 부메랑 날개각 |
| **테이블 캘리브레이션** | **가상의 벽 캘리브레이션** — 구조가 동일하다 |

> **같은 코어 위에 소재만 바꿔 얹는 구조.** 3cushions가 P1(물리 솔버)에서 만드는 것이
> 여기서 그대로 재사용되므로, **두 프로젝트는 순서를 정해 하나의 엔진을 나눠 쓰는 게 맞다.**
