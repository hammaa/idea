# 3쿠션 당구 포지션 해법기 (3-Cushion Position Solver)

> 공 배치를 넣으면 **해법을 선으로 그려주고**, 그 해법을 **다이아몬드 시스템 계산으로 설명**해 주는 도구.
> 당점 팁 단위 회전에 따른 1~8쿠션 도달 포인트, 스쿼트·커브 보정까지 계산한다.

| 항목 | 내용 |
|---|---|
| 등록일 | 2026-08-30 |
| 상태 | ⚠️ **아이디어 등록 (경쟁 서비스 2건 확인 — 재정의 필요)** |
| 원안 | 포지션 → 해법 선 + 시스템 계산 보조 + 게임 플레이 + AI 연결 |

---

## 원안 (사용자 제시)

1. 3쿠션 포지션을 주면 **해법을 구한다**
2. **파이브앤하프 / 플러스 / 플러스투** 등 기본 시스템 **데모 플레이**
3. **당점을 팁 단위로 회전시킬 때 1·2·3···8쿠션의 포인트를 정확히** 알려준다
4. **밀어치기 / 그냥 치기** 등에 따른 **스쿼트·커브 계산**까지 포함
5. **게임처럼 쳐도 되고**, 정확한 해법을 **선으로 그려준다**
6. 해법에 맞는 **시스템 계산을 보조로** 붙인다
7. **AI 연결**

## 그래서 무엇이 남는가 — 원안에서 유일하게 남의 것과 다른 것

원안 7개 중 **3번**이 경쟁 서비스에 없다.

> **"당점을 팁 단위로 회전시킬 때 1·2·3···8쿠션의 포인트를 정확히 알려주기"**

경쟁 서비스는 **하나의 궤적**을 그린다. 원안은 **팁을 바꿀 때 궤적이 어떻게 움직이는지**를 요구한다.
이건 답이 아니라 **답의 미분(민감도)** 이고, 성격이 완전히 다른 출력이다.

| | 경쟁 서비스 | 원안 3번 |
|---|---|---|
| 출력 | "이렇게 치세요" (해 1개) | "1팁당 3쿠션 도착점이 N포인트 이동" (감도) |
| 쓰임 | 답 확인 | **틀린 이유 진단** |
| 테이블에서 | 못 씀 (경기 중 폰 못 봄) | **머릿속에 남는 규칙** |

그리고 여기서 이 아이디어의 핵심 가설이 나온다.

> **다이아몬드 시스템은 물리의 근사치다. 시스템 계산과 물리 시뮬레이션은 반드시 어긋난다.**
> **가치 있는 제품은 답을 주는 쪽이 아니라, 그 어긋남의 크기와 원인을 보여주는 쪽이다.**
>
> *"시스템은 1쿠션 30을 가리키는데 당신의 당점·속도에서 실제는 32다. 차이 2포인트의 원인은 스쿼트다."*

## 이 아이디어의 강점 — 자체 검증이 된다

[프롬프트 팩 06-카테고리-확장](../prompt-pack/06-카테고리-확장.md)에서 세운 원칙을 그대로 적용한다.

> **숨은 제약: 자체 검증 가능성.** 직접 겪지 않은 도메인은 결과의 정오를 판별할 수 없어 환각이 그대로 출고된다.
> 그래서 **법률·세무·의료는 이 모델로 건드리지 않는다.**

**당구는 이 축에서 만점이다.** 계산이 맞았는지는 **당구대에 가서 쳐 보면 즉시 판명**된다.
검증 비용이 낮고, 피드백이 즉각적이고, 정답이 객관적이다 — 리서치 도메인으로서 드물게 좋은 조건이다.

⚠️ **단, 전제 조건이 있다.** 이 이점은 **만드는 사람이 3쿠션을 칠 줄 알 때만** 성립한다.
→ [01-기획.md](01-기획.md) 6절의 미해결 질문.
