# 정부 정보 공개 (Government Information Access)

> 대한민국 정부·공공기관이 보유한 정보에 **어떤 경로로 무엇을 얻을 수 있는가**를 정리한 조사 문서.

| 항목 | 내용 |
|---|---|
| 조사일 | 2026-08-30 |
| 상태 | 📚 **레퍼런스 조사** (아이디어 후보 발굴용, 특정 아이디어 아님) |
| 목적 | 아이디어의 원재료 탐색 — 어떤 데이터가 이미 공짜로 열려 있고, 무엇이 청구해야 나오고, 무엇이 막혀 있는가 |

---

## 가장 먼저 알아야 할 것 — 제도가 **하나가 아니다**

"정부 정보 공개"는 흔히 한 덩어리로 불리지만, **근거 법률도 운영 주체도 성격도 완전히 다른 5개의 경로**다.
이걸 구분하지 못하면 "공공데이터포털에 없으니 없는 정보"라고 오판하게 된다.

| # | 경로 | 근거 | 성격 | 대상 | 비용/시간 |
|:-:|---|---|---|---|---|
| **1** | **정보공개청구** | 정보공개법 | **Pull** — 내가 지정해서 달라고 함 | 이미 생산·보유 중인 **문서** | 무료~실비, **10일**(+10일) |
| **2** | **공공데이터 개방** | 공공데이터법 | **Push** — 기관이 미리 열어둠 | 기계판독 가능한 **데이터셋/API** | 즉시, 무료 |
| **3** | **의무 공시** | 개별법 (자본시장법 등) | **Push** — 법으로 강제된 공표 | 기업·공공기관의 정형 보고 | 즉시, 무료 |
| **4** | **통계·마이크로데이터** | 통계법 | 승인·심사 후 제공 | 원표본 단위 자료 | 심사 필요 |
| **5** | **제한구역 접근** | 개인정보보호법 등 | 반출 금지, **가서 분석** | 민감·식별 위험 데이터 | 신청·심사·현장 |

> **핵심 판단 순서:** ② 이미 열려 있나 → ③ 공시 의무가 있나 → ① 청구하면 나오나 → ④⑤ 심사받아야 하나
> 대부분의 사람이 ①부터 시도하는데, **②③에 이미 있는 것을 청구하면 10일을 낭비**한다.

## 규모 — 얼마나 열려 있나

| 지표 | 수치 | 기준 |
|---|---:|---|
| 공공데이터포털 개방 데이터 | **10만 건** | 2024년 12월 말 (2013년 말 5,272건 → **20배**) |
| 민간 활용 (다운로드 + API 요청) | **7,579만 건** | 2024년 12월 말 (2013년 말 1.4만 건 → **5,413배**) |
| 국가중점데이터 | **217종** | 고가치 데이터로 지정·개방 |
| 국가승인통계 (KOSIS) | **약 1,000종 / 300여 기관** | — |
| 정보공개 처리 건수 | **1,017,486건** | 2023년, 전 공공기관 |
| 정보공개율 | **94.3%** | 2023년 (최근 5년 약 94~95% 유지) |

> **연 100만 건의 청구가 처리되고 그중 94%가 공개된다.** 정보공개청구는 예외적 수단이 아니라 **일상적 인프라**다.

## 조사하며 나온 관찰 — 아이디어 관점

여기 기록만 하고, 사업화 판단은 하지 않는다 (기존 아이디어 문서들과 달리 이건 **레퍼런스**다).

| 관찰 | 근거 |
|---|---|
| **개방량과 활용량의 증가율이 다르다** | 데이터는 20배, 활용은 5,413배. 병목이 공급이 아니라 **가공·해석** 쪽에 있다는 신호 |
| **원본은 공짜인데 쓸 수 있는 형태가 아니다** | HWP/PDF 스캔, 비표준 코드, 기관별 상이한 스키마 — 정제가 곧 부가가치 |
| **청구 자체가 진입장벽** | 어느 기관이 그 문서를 갖고 있는지 아는 것이 가장 어렵다. 연 100만 건이 처리되지만 대부분 **반복되는 질문** |
| **비공개 사유의 절반이 개인정보·영업비밀** | 개인정보 34% + 영업비밀 14% = 48%. 이 벽은 가공으로 못 넘고 ⑤ 제한구역 경로로만 우회 |
| **조직 개편으로 출처가 바뀐다** | 2025-10-01 통계청 → **국가데이터처**, 특허청 → **지식재산처**. 기관명·URL 하드코딩은 부채가 된다 |
| **단일 장애점이 존재한다** | 2025-09-26 국가정보자원관리원 화재로 정보공개포털이 **약 5주간 중단**. 정부 API에 의존하는 서비스의 실재하는 리스크 |
